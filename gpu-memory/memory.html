显存、内存与存储墙

1. 六种“存储”不能混为一谈

技术本质主要应用强项主要局限
SRAM静态存储单元GPU 内部缓存极低延迟面积大、每 GB 昂贵
DDR5 / RDIMMDRAMCPU 系统内存容量、可扩展性、成本平衡相较 HBM 带宽密度低
LPDDR5X / LPDDR6低功耗 DRAM手机、轻薄电脑、部分服务器低功耗接口、平台和容量约束
GDDR7高速图形 DRAM独立显卡高频、较经济的板卡设计每比特能耗与接口约束
HBM3E / HBM4TSV 三维堆叠 DRAMAI 加速器极宽接口、高带宽和带宽能效封装难、产能贵、容量昂贵
NAND / SSD非易失性闪存模型文件、持久存储容量大、断电保存读取延迟与写入特征不适合直接替代 DRAM
最重要的区分：HBM 与 GDDR 都是 DRAM 的具体组织和接口方式；NAND 是另一种存储介质。HBM 的目标不是在所有方面更好，而是以更高成本换取极高的近计算带宽。

2. 最基础的带宽公式

理论带宽 = 数据总线位宽 × 每引脚传输速率 ÷ 8
HBM4 示例

2,048 bit × 13 Gb/s

3.328 TB/s

单堆栈峰值；13Gb/s 属于三星公开的最高能力，不等于所有量产器件的保证工作频率。[来源]

GDDR7 示例

512 bit × 28 Gb/s

1.792 TB/s

这是 RTX 5090 级别的显存总线带宽，对应 NVIDIA 官方 1792 GB/s 规格。[来源]

实际程序读到的带宽往往低于理论峰值，还受到访问连续性、缓存命中、读写混合、温度和功耗约束。这也是为什么只比较 TB/s 很容易误判 AI 性能。

交互练习 · 带宽计算器

试着改变总线位宽和速率

3.328 TB/s

十进制 TB/s；忽略协议开销与实际访问效率。把位宽改成 512、速率改成 52，就能直观理解 SPHBM4 的 4:1 串行化思想。

3. HBM 的架构创新在哪里？

代际接口宽度技术重点2026 年所处阶段
HBM2 / HBM2E1024 bit让高带宽堆叠内存成为 AI GPU 主流技术老一代、仍有应用
HBM31024 bit更高信号速度和容量成熟产品
HBM3E1024 bit进一步提高速度和堆叠容量H200 / Blackwell 主要采用
HBM42048 bit总线翻倍、基底逻辑升级、带宽提高2026 已量产
HBM4E2048 bit 路线16Gb/s/pin 级样品、高性能与热设计2026 已送样
HBM5随标准及实现演进更高堆叠密度、定制化、互连优化路线研究

HBM 的核心难题，不是“层数越多越好”

每增加一层，就增加晶圆减薄、TSV、芯片对位、层间连接、封装厚度、散热和缺陷检测的负担。需要同时优化单堆栈容量 × 带宽 × 良率 × 能耗，任何一项失衡都可能使单位可用算力成本上升。

延伸阅读：HBM 如何堆叠，混合键合，HBM4 的 2026 年量产及送样时间线。

4. GDDR7 和 HBM4，究竟怎么选？

GDDR7

高速公路：较窄、但每条线路跑得快

颗粒通常沿 GPU 周围的印制电路板布置，通过较宽但远小于 HBM 的总线高速传输。PAM3 三电平信号是重要创新。

适合：游戏显卡、专业工作站、成本和板卡制造约束更强的产品。

HBM4

多车道高速路：极宽总线、短距离

数千条短距离并行通道，由 TSV、基底芯片和先进封装协同构成。系统级带宽可跨多个堆栈累加。

适合：高带宽密度、高能效需求的 AI 加速器。

不要把“HBM 的单堆栈带宽”与“GDDR 一整张显卡的总带宽”直接比较；也不要把显存容量和带宽混为同一个指标。

5. 为什么 HBM 会挤占 DDR5 产能？

AI 训练 / 推理增长模型 + KV Cache + 并发
HBM 需求增加高端 GPU 要更多堆栈
DRAM 产能调整先进晶圆与工艺资源竞争
先进封装瓶颈键合、CoWoS、测试
其他内存承压DDR5、部分 LPDDR/GDDR

HBM 并非与所有 DDR 产品完全共享同一条产线，但其扩张会竞争部分先进 DRAM 晶圆、设备、工程与资本资源。产能转换、产线建设和大客户长期锁量又放大了供需波动。

行业研究时要区分：HBM 位元需求、DRAM 晶圆投片量、良率、合约价格、现货价格、封装产能，以及最终交付的 GPU 数量。

6. 专家级思考题

  1. 同样都是 288GB 显存，为什么实际大模型吞吐量可能差别很大？
  2. HBM4 的 2048 位接口为什么同时加重了逻辑基底和封装压力？
  3. 既然 GDDR7 成本较低，为什么高端 AI GPU 没有全面转向 GDDR7？
  4. 大模型推理在 Prefill 与 Decode 两个阶段，对算力和带宽的需求为何不同？

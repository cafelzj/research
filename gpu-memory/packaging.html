03 / ADVANCED PACKAGING

先进封装：AI 芯片的第二战场

把“制造一个晶体管”与“把多个昂贵芯片组织成系统”分开看。HBM 内部封装、GPU+HBM 系统级封装，以及供电、散热和测试构成了不同的技术壁垒。

分层CoWoSHBM 堆叠混合键合供电翘曲散热良率测试未来封装

1. 别把两种封装混为一谈

HBM 内部

把十几层 DRAM 堆成一摞

核心工艺包括 TSV、减薄、层间微凸点或混合键合、模塑材料、热压和堆栈测试。

GPU + HBM 系统级

把 GPU 与多个 HBM 堆栈连成系统

核心工艺包括 CoWoS、硅中介层、RDL、局部硅桥、有机封装基板、供电散热和最终测试。

一张 AI GPU 能否交付，取决于两个层级同时成功。 HBM 厂商交付堆栈，不等于已经造出了可用的 H200 或 Rubin 加速器。

2. CoWoS 的三种路线

技术物理结构适合场景制造瓶颈
CoWoS-S连续硅中介层高密度连接、成熟方案大面积硅、成本及良率
CoWoS-R重布线层为主的中介结构尺寸与成本灵活性精细线路与信号损耗
CoWoS-L重布线层 + 局部硅桥大规模异构芯粒和 HBM 集成硅桥放置、材料异质性、封装翘曲

CoWoS-L 不是“封装更高级”这么简单，而是针对更大封装面积下的连接密度、成本和量产可行性做结构权衡。

3. HBM 堆叠的工艺链

DRAM 晶圆单元、逻辑、良率
TSV 制造深孔刻蚀、绝缘、填铜
晶圆减薄临时键合、机械强度
键合 + 填充微凸点、模塑
堆栈测试连接、热、可靠性

TSV：芯片里的垂直电梯

在硅内部打通孔并填入导体，连通上下层；挑战是高深宽比、空洞、对位和铜硅热膨胀差。

超薄晶圆

薄硅片有助于限制堆叠总高度，但减薄后容易破片与翘曲，临时键合/剥离成为关键。

MR-MUF

批量回流焊形成连接，再进行模塑填充，SK 海力士在 HBM4 继续发展 Advanced MR-MUF。

TC-NCF

通过热压与非导电薄膜实现堆叠连接；关键在精准温压控制、薄膜均匀性和缺陷管理。

4. 混合键合：为什么受到重视？

微凸点连接

技术成熟度较高，但间距、厚度和电气寄生效应可能成为进一步微缩的限制。

铜 / 介质混合键合

有潜力提高连接密度及能效，但对晶圆平坦度、洁净度、金属高度与对位要求更苛刻。

HBM4 并不必然采用混合键合。混合键合已经用于部分商业三维芯片，但应用到未来更高层数的 HBM 仍需考虑成本、可靠性及量产节拍。

5. 供电与信号完整性：不只是工艺问题

超大电流供电
I = P / V

假设计算核心功率为 1000W、供电电压 0.8V，则理论电流约 1250A；仅 10μΩ 的路径电阻对应 I²R 损耗约 15.6W。

这是原理计算，不是 H200 或 Rubin 的实测核心电流。

高速互连

信号完整性（SI）

线太细、太密时可能出现串扰、时序偏差、反射、阻抗不连续和电源噪声。HBM4 的 2048 位宽接口让连接与基底芯片设计更困难。

未来垂直供电、电源分配网络（PDN）、去耦电容及封装内供电将越来越重要。并非所有“供电损失”都发生在 GPU 硅裸片内部，封装和模组同样参与。

6. 超大封装面临翘曲、热阻和材料失配

关键现象背后的物理原因工程后果
翘曲 Warpage硅、铜、基板和模塑材料的热膨胀不同接点失准、裂纹、装配困难
热阻过高热量穿过多层材料与界面降频、可靠性下降
电迁移高电流密度促进金属原子迁移连接电阻增加、开路或短路
分层 / 空洞界面应力、污染或填充不良导热恶化和失效风险
基板尺寸效应面积增加放大材料误差和形变大尺寸 CoWoS 量产难度提升

2026 年 SK 海力士发布 iHBM 散热设计，在封装内加入导热绝缘元件；厂商测试显示热阻降低约 30%，但不等于所有产品已经量产搭载。[官方资料]

7. 良率和测试为什么越来越重要？

“每颗都合格”仍不够

0.99¹² ≈ 88.6%

若假设 12 颗裸片合格率各 99%，且完全独立，随机组合全部合格的概率约 88.6%。仅是教学示例，不是实际 HBM 良率。

已知良品裸片（KGD）

在堆叠前尽可能筛除故障芯片，减小昂贵封装完成后才报废的概率；但还需要检验 TSV、键合、模组与系统。

晶圆测试单颗器件
HBM 堆栈测试层间互连
封装中间测试关键互连
最终功能测试带宽功耗
服务器整机测试应用与可靠性
量产判断标准：不要只问“能不能做出样品”，还要问每小时产量、最终封装良率、返工能力、测试覆盖率、热循环寿命以及每个合格模组的真实成本。

8. 未来技术路线：横向做大还是纵向堆高？

2.5D

CoWoS-L / 硅桥

多个计算芯粒与 HBM 并排放置，在局部需要的区域提供高密度互连；挑战是面积、热机械和基板。

3D

SoIC / 混合键合

把计算、缓存等裸片直接垂直堆叠，降低互连距离；挑战是层间散热和制造良率。

SUBSTRATE

玻璃基板 / TGV

有望提高尺寸稳定性，但玻璃微裂纹、穿孔填铜、界面脱层和大规模制造仍难。

INTERCONNECT

CPO / 光互连

尝试降低长距离互连的功耗与损耗；不是直接替代 HBM 内部的电连接。

延伸：未来架构发展、设备材料和封装厂商分工。

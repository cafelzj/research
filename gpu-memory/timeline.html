4. 接下来要关注哪些验证节点？

HBM4E

客户送样 → 资格认证 → 良率爬坡 → 批量供货；16Gb/s 的样品最高速率能否大规模稳定实现？

HBM5 / 更高层数

堆叠高度、混合键合、热阻、电源与逻辑基底；不要将预测当成标准。

Rubin / MI455X

规格公告 → 系统部署 → 可复现的训练和推理性能 → 每 Token 电费及总拥有成本。

SPHBM4 / HBF

标准发布只是起点；观察供应商是否有实际样品、平台支持、客户部署和单位成本收益。

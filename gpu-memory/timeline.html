INTERACTIVE CHRONOLOGY

1. 按厂商、类型与年份观察事件

时间线的年月精度因厂商资料不同而异。“发布 / 披露”只说明公开，不代表已规模量产或所有客户可购买。

2. 读事件，也要读规格版本

2026年11月8日核验时，NVIDIA 架构正文与 HGX 单GPU表给出最高22 TB/s，Vera Rubin NVL72页的单GPU表给出19.2 TB/s。两种当前官方表述并存，差异原因未核实，不能仅按页面先后推断为已经确认的降规格。

3. 接下来要关注哪些验证节点？

HBM4E

客户送样 → 资格认证 → 良率爬坡 → 批量供货；16Gb/s 的样品最高速率能否大规模稳定实现？

HBM5 / 更高层数

堆叠高度、混合键合、热阻、电源与逻辑基底；不要将预测当成标准。

Rubin / MI455X

规格公告 → 系统部署 → 可复现的训练和推理性能 → 每 Token 电费及总拥有成本。

SPHBM4 / HBF

标准发布只是起点；观察供应商是否有实际样品、平台支持、客户部署和单位成本收益。

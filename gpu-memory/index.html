三条贯穿全部讨论的主线

算力为什么离不开显存与封装？

算得快

Tensor Core 的吞吐提高得再快，也要有足够数据可计算。

送得进

HBM 带宽、中介层互连和缓存决定实际可以喂给 GPU 多少数据。

造得出

先进封装、供电、散热、测试和良率，决定产品是否能稳定批量交付。

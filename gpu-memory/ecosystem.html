GPU产业链

沿设计、制造、存储、封装测试与系统交付，观察每一环节的投入、产出和限制。

产业链主要公司稀缺原因研究指标判断框架

1. 沿交付物看产业链，沿约束找瓶颈

研究产业链先标出每一环节交付什么：设计、逻辑裸片、合格 HBM 堆栈、完成封装的器件，还是能运行任务的节点与机柜。逻辑芯片和 HBM 可并行制造，最终按规格、良率与交期汇合；单项扩产不能直接换算成可交付 GPU 数量。

下表把环节与观察指标对应起来，厂商名称只说明角色。Fabless 是设计经营模式，晶圆厂负责制造；HBM 是存储器，CoWoS 是 TSMC 的封装平台。OSAT 表示委外封装测试服务，具体 GPU 的供应关系仍须有对应产品、工序与认证证据。

GPU产业链：环节与有效交付
环节投入 → 交付物角色示例观察什么 / 边界
芯片与系统设计任务需求、软件栈、接口与制造设计规则 → 架构、芯片设计及系统规格NVIDIA、AMD 等设计厂商应用吞吐、能效与软件适配；设计变更能否通过验证并进入制造。 Fabless 不等于拥有晶圆制造能力；设计厂商的产品名称，也不能单独证明其每道工序由谁承接。
逻辑晶圆制造经验证的设计、晶圆、设备与工艺材料 → 可进入后续筛选与封装的逻辑裸片TSMC、Samsung Foundry、Intel Foundry 等制造角色工艺匹配、晶圆良率和有效裸片产出；它们约束计算芯片交付。 逻辑制程产能不是 DRAM 产能，也不是先进封装产能；列出晶圆厂不代表确认某型号采用其工艺。
DRAM 制造与 HBM 堆叠DRAM 裸片、堆栈所需基底与 TSV / 键合工序 → 满足容量、速率与可靠性要求的 HBM 堆栈SK hynix、Samsung、Micron 等存储厂商堆叠良率、测试、热特性与客户认证；合格堆栈数量约束可装配数量。 HBM 堆叠与 GPU 加 HBM 的系统封装是两道环节；某代产品公告不能外推所有客户均已量产采用。
先进封装与基板合格逻辑裸片、HBM、中介层或桥接互连、封装基板 → 完成高密度互连的 GPU 与显存封装器件TSMC CoWoS 等封装平台；基板与材料厂商按工序另查面积、布线、翘曲、封装良率与基板交期；材料和设备节拍共同影响有效交付。 CoWoS 是特定平台名称，不能代指全部先进封装；封装平台、基板制造商、键合设备商分别交付不同对象。
筛选、封装测试与可靠性验证晶圆、裸片、封装器件及对应测试程序 → 通过相应测试与分档的器件或模组封装平台及 ASE 等封测服务商（能力示例）测试覆盖、测试时间与失效率；测试能力和前序良率会限制合格品放行。 测试贯穿多个阶段，并非只在最后一次完成；OSAT 身份或公开能力不自动证明它承接某款 GPU。
模组、节点与机柜集成GPU 器件、板卡、CPU、网络、电源、冷却与软件 → 通过整机验证、可部署运行的节点或机柜系统厂商、ODM 与网络、供电、冷却供应商系统联调、互连、功率与冷却预算；最终以可运行任务的交付和实际吞吐衡量。 GPU 器件充足不保证机柜按期交付；节点、机柜和集群的容量与带宽统计口径须分别核对。

3. 2026 年内存为什么紧张？五个因果层次

DEMAND

AI 计算需求

更大模型、长上下文、多 Agent 并发、推理缓存与高带宽内存共同拉动数据中心 DRAM 需求。

PRODUCTION

HBM 争夺先进 DRAM 资源

更大的裸片面积与复杂工艺，使相同容量 HBM 消耗更多制造和封装资源。

PACKAGING

封装不是无限产能

CoWoS、HBM 堆叠、精密基板、键合和测试都可能成为独立瓶颈。

CAPITAL

扩产建设周期长

厂房、设备交付、工艺调试和客户验证往往以年度计，而需求可以快速变化。

COMMERCIAL

长期合同锁定产能

大客户提前签约，留给其他厂商的灵活供给减少。

CYCLE

存储仍有周期性

库存、需求过热、价格破坏需求和新增产能可能使供需从紧张转向宽松。

4. 行业研究：如何分辨通用指标和本行业特有指标？

指标层级典型指标为什么要看
全部制造业通用收入、毛利率、资本开支、产能利用率评价经营与景气，不是半导体独有
半导体制造共性晶圆投片、良率、制程、设备稼动率评价有效产出和制造能力
存储器重点位元出货、每比特成本、合约价/现货价、库存存储供需和价格周期
HBM 特有或特别关键堆栈层数、每堆栈容量/带宽、热阻、堆叠良率决定高端内存的性能与单位成本
先进封装特别关键中介层面积、连接间距、封装良率、测试时间决定高价值系统级封装能否稳定交付
AI GPU 系统关键Token/s、Token/J、实际带宽、通信开销让理论性能与业务价值挂钩

“良率”不是 HBM 行业特有指标；但多层堆叠良率及其对成本的放大作用，对于 HBM 特别重要。同理，资本开支是行业通用指标，CoWoS 封装产能与关键键合设备节拍则更具产业特征。

5. 真正像专家一样判断技术价值

分析一个新技术，至少回答五个问题

  1. 解决哪个瓶颈？算力、带宽、容量、成本、功耗还是良率？
  2. 改变哪一层？存储介质、逻辑芯片、封装、服务器互连还是软件？
  3. 技术成熟到什么程度？论文、实验室样品、客户送样、认证还是量产？
  4. 经济性怎样？以单位有效推理吞吐或单位交付容量衡量是否值得部署。
  5. 谁控制瓶颈？设计、工艺、设备、基板、测试还是最终客户？
最值得跟踪的竞争关系：SK 海力士 / 三星 / 美光的 HBM4E 量产能力；TSMC 的 CoWoS-L 与 3D 集成；NVIDIA 与 AMD 对算力、显存、互连和软件栈的系统优化。

06 / COMPANIES & SUPPLY CHAIN

产业链、技术壁垒与稀缺性

从芯片设计、先进 DRAM 制造、HBM 堆叠到 CoWoS、基板、测试和机柜系统，研究每个环节的真正壁垒与价值分配。

产业链主要公司稀缺原因研究指标判断框架

1. 一块 AI GPU 是如何产生的？

GPU 架构设计NVIDIA / AMD / Intel
晶圆制造逻辑芯片与 DRAM
HBM 堆叠TSV、键合、测试
系统级封装CoWoS / 基板 / KGD
GPU 与机柜电源、冷却、互连

这是概念流程，实际制造可并行进行：HBM 堆栈可以在 GPU 裸片制造期间独立生产。最终系统需要在准确时间汇合多个供应链环节。

产业链最重要的误区：GPU 芯片制造能力、HBM 量产能力、CoWoS 产能和整机柜交付能力是不同的资源。某个环节充足，不代表最终 GPU 一定充足。

2. 重点企业与竞争环节

产业环节代表企业核心技术壁垒观察事项
GPU / AI 加速器设计NVIDIA、AMD、Intel架构、计算单元、软件栈与高速互连实际应用吞吐、能效、生态
先进逻辑制造TSMC、Samsung Foundry、Intel Foundry先进制程、晶圆良率、逻辑基底芯片制程、封装协同与客户认证
先进 DRAM / HBMSK hynix、Samsung、MicronDRAM 制程、TSV、堆叠与热管理HBM4 交付、HBM4E 良率
中国 DRAM / NAND 发展长鑫存储、长江存储国内存储工艺、设备和材料体系建设注意 DRAM 与 NAND 业务区别
先进封装平台TSMC、Samsung、Intel、日月光/矽品、Amkor硅中介层、RDL、封装良率和测试是否具备具体 GPU 所需工艺认证
键合与精密装备Hanmi、BESI、ASMPT 等高精度对位、热压、混合键合设备精度、节拍、售后与良率
工艺设备 / 检测Applied Materials、Tokyo Electron、KLA 等沉积、刻蚀、抛光、缺陷检测不同公司覆盖工序不同
系统互连 / 网络NVIDIA、Broadcom、Arista 等GPU scale-up、交换、光模块、网络软件通信占比、拓扑与功耗

公司为代表性示例，并不等于所有公司都为某个具体 GPU 或 HBM4 项目供货。某家公司拥有封装能力，也不代表是 CoWoS 的直接供应商。

3. 2026 年内存为什么紧张？五个因果层次

DEMAND

AI 计算需求

更大模型、长上下文、多 Agent 并发、推理缓存与高带宽内存共同拉动数据中心 DRAM 需求。

PRODUCTION

HBM 争夺先进 DRAM 资源

更大的裸片面积与复杂工艺，使相同容量 HBM 消耗更多制造和封装资源。

PACKAGING

封装不是无限产能

CoWoS、HBM 堆叠、精密基板、键合和测试都可能成为独立瓶颈。

CAPITAL

扩产建设周期长

厂房、设备交付、工艺调试和客户验证往往以年度计，而需求可以快速变化。

COMMERCIAL

长期合同锁定产能

大客户提前签约，留给其他厂商的灵活供给减少。

CYCLE

存储仍有周期性

库存、需求过热、价格破坏需求和新增产能可能使供需从紧张转向宽松。

4. 行业研究：如何分辨通用指标和本行业特有指标？

指标层级典型指标为什么要看
全部制造业通用收入、毛利率、资本开支、产能利用率评价经营与景气，不是半导体独有
半导体制造共性晶圆投片、良率、制程、设备稼动率评价有效产出和制造能力
存储器重点位元出货、每比特成本、合约价/现货价、库存存储供需和价格周期
HBM 特有或特别关键堆栈层数、每堆栈容量/带宽、热阻、堆叠良率决定高端内存的性能与单位成本
先进封装特别关键中介层面积、连接间距、封装良率、测试时间决定高价值系统级封装能否稳定交付
AI GPU 系统关键Token/s、Token/J、实际带宽、通信开销让理论性能与业务价值挂钩

“良率”不是 HBM 行业特有指标；但多层堆叠良率及其对成本的放大作用，对于 HBM 特别重要。同理，资本开支是行业通用指标，CoWoS 封装产能与关键键合设备节拍则更具产业特征。

5. 真正像专家一样判断技术价值

分析一个新技术，至少回答五个问题

  1. 解决哪个瓶颈？算力、带宽、容量、成本、功耗还是良率？
  2. 改变哪一层？存储介质、逻辑芯片、封装、服务器互连还是软件？
  3. 技术成熟到什么程度？论文、实验室样品、客户送样、认证还是量产？
  4. 经济性怎样？以单位有效推理吞吐或单位交付容量衡量是否值得部署。
  5. 谁控制瓶颈？设计、工艺、设备、基板、测试还是最终客户？
最值得跟踪的竞争关系：SK 海力士 / 三星 / 美光的 HBM4E 量产能力；TSMC 的 CoWoS-L 与 3D 集成；NVIDIA 与 AMD 对算力、显存、互连和软件栈的系统优化。

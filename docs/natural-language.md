# 自然语言图表协议

当前是浏览器中的规则解析器，不是大模型服务。推荐使用标准术语和逗号分隔的参数，完整输入示例：

> 全部产品近12个月气泡图，X轴价格，Y轴开工率，大小按产量，点大小40px，三角形，紫色，图例在顶部

处理链路为 `原句 → 规范化 → 字段/术语匹配 → 结构化配置 → 校验 → ECharts option → 渲染`。

1. 规范化全角 X / Y 和冒号，识别图形、月份、产品、字段及样式术语。
2. 从当前数据集读取合法字段；已知字段有中文别名，例如 `价格 → price`、`产量 → output`、`开工率 → rate`。额外 CSV 数值列可直接使用列名。
3. 生成配置对象。例如示例的核心字段为：

```json
{
  "type": "bubble",
  "period": 12,
  "x": "price",
  "y": "rate",
  "sizeField": "output",
  "size": 40,
  "symbol": "triangle",
  "palette": "purple",
  "legendShow": true,
  "legendPosition": "top"
}
```

4. 校验图表类型枚举、字段存在性、数值类型、日期范围、像素大小、颜色和形状等。气泡面积映射正数指标；饼图不接受负值或全零。出现错误时保留当前图，不应用半份新配置。
5. `buildOption()` 将配置变成 Apache ECharts 5.6.0 的 `series`、`xAxis`、`yAxis`、`legend` 和样式参数，然后由 ECharts 绘制。自然语言不是 JavaScript，不会作为代码执行。

网页的“本次解析报告”展示原句、规范化结果、生成时完整配置 JSON 和校验/未识别提示。手动调整后的设置以配置区为准，报告保留生成时快照。

## 约定与边界

| 参数 | 支持的术语与含义 |
| --- | --- |
| 图形 | 散点图、气泡图、折线图、柱状图、堆叠柱状图、饼图、环形图；一条指令一个图形 |
| 字段 | X轴/横轴、Y轴/纵轴，接已知中文名或实际列名；散点/气泡的 X 为数值，Y 始终为数值 |
| 大小映射 | “大小按产量”，表示气泡面积随数据变化 |
| 像素尺寸 | “点大小24px”“气泡最大直径48px”；范围8–64，折线标记最大18 |
| 形状 | 圆形、方形、三角形、菱形、圆角方形；只用于点标记 |
| 配色 | 红蓝、紫色、绿色、蓝色、红色，或“颜色#2377ad”；当前按产品分组，不支持逐产品自然语言配色 |
| 图例 | 显示图例、隐藏图例、图例在顶部、图例在底部；图例分组固定为产品 |
| 范围 | 近N个月，N为1–24；饼图可用 YYYY-MM 或 YYYY年M月 |
| 产品 | 使用数据中的准确产品名称，或“全部产品” |
| 子图/分面/双轴 | 尚不支持；明确报错，请分别生成单图 |

未指定的参数沿用当前配置。散点图未显式写 X/Y 时按提及字段顺序推断；折线图和柱状图默认月份 X 轴，饼图未写月份时取最新月份。网页报告提示用户核对推断结果。

明确指定未知字段、超范围尺寸、多个冲突图形/配色等要求会报错。其他未匹配文本在报告中显示为“未识别片段”，不作为参数执行；“漂亮一点”“更大一些”没有稳定数值语义，请改为标准术语或使用配置控件。

未来若接入大模型，应让模型输出同样的受约束 JSON，通过相同的字段与数据校验后才渲染。子图需要新增面板配置数组、布局和各自坐标轴索引，并扩展校验器与 `buildOption()`；当前网页没有实现这些参数。

# 家电研究框架与学习手册

入口为 [`appliances.html`](https://cafelzj.github.io/research/appliances.html)。申万家用电器 `atlas.html?sw=801110` 和原专题 `atlas.html?industry=appliances` 均可进入。本手册面向学习研究方法，以中国家电为主、全球公司作商业模式对照；上下游及海外研究对象不等同申万家电成分股名单。

## 内容与阅读顺序

按品类解释客户需求、部件与材料、整机制造、渠道、安装售后和利润形成，再连接到公司比较、核心技术、最新披露、数据字典和研究训练。空调与热泵、冰箱、洗烘、厨电、厨房小电、个护、清洁电器、电视、商用暖通以及热水净水分别组织，不套用同一盈利逻辑。

第一次阅读可以先完成行业地图、选择一个品类和两家公司，再阅读指标口径与财报示范。进阶阅读进入技术经济性、库存与现金、量价结构、全球化与正常化估值。十周练习逐项要求表格、图、模型或报告，并给验收标准及反方审查要求。网页中的四个教学模型都可手工复算。

## 证据边界

资料核验截至2026年11月7日。最新财报示范分别标明报告期、披露日与原件定位；同一公司单季和累计、国内会计准则和IFRS不能混算。公司引用第三方市场数据时，结论仍限于该样本与口径。

技术动态按所引披露时点标注成熟应用、产品预告、上市计划、规范发布或原型展示。未确认的后续交付不推断为已经发生或尚未发生。企业发布材料用于理解宣称和待验证机制，不视为独立测评、实际销量或持续盈利证明。标准注明测试对象与使用边界，公开摘要不冒充已读取付费全文。

每项数据注明单位、频率、口径、权限、支持改善和推翻判断的组合。商业数据库不伪装成免费实时接口；没有接入当前行情或自动采集。模型参数明确为教学假设，不能引用为实测行业均值。公司和部件举例说明研究角色，不能据此推断真实供货关系、份额或证券推荐。

## 维护

正文源为 `assets/appliances-research.json`，分为 `chains`、`companyResearch`、`technology`、`measurement` 及汇总 `sources`。来源ID以 `chain-`、`co-`、`tech-`、`metric-` 区分，正文引用只能指向已登记的来源。更新事实时同步修改日期、证据范围和对照解释，保留事实、推断与教学假设的区分。

运行 `python3 scripts/build_appliances.py` 生成完整静态页面；不依赖运行时请求JSON。脚本只增强搜索、分类筛选、深链接展开与目录，禁用JavaScript仍可逐章阅读。页面不读写私人笔记或浏览器存储。

验证命令：

```sh
python3 scripts/check_appliances.py
python3 scripts/build_appliances.py --check
python3 scripts/test_appliances.py http://127.0.0.1:8000/
```

一致性检查覆盖来源引用、日期上界、表格列数、锚点唯一性、来源和正文链接、独立算术复算与生成文件匹配。浏览器检查覆盖两处行业入口、搜索与分类组合、跨筛选定位、来源展开、深链接重载、手机大纲、320/390像素布局和禁用脚本阅读。它们不代替对原始来源与研究推断的专业审稿。

GitHub Pages工作流同时运行本手册检查，部署后逐文件核对公网内容与提交一致，再运行公网阅读流程检查。

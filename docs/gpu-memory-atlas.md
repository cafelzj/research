# GPU 与显存技术专题部署

入口为 [GPU 与显存技术知识网络](https://cafelzj.github.io/research/gpu-memory/index.html)，从“日常研究”及中餐、日料专题的研究导航进入。专题每页顶部可返回日常研究。

内容最初来自用户上传的 `gpu_memory_atlas_2026.zip`。现有12个静态页面，按型号与代际、内部架构、技术难点、产业链、时间线五条研究主线组织；显存、先进封装、前沿路线作为技术深读，词典、问题索引、资料作为查阅工具。目录保留相对路径，无运行时构建、CDN或外部字体依赖。

首次接入增加了主站入口、各页返回导航、导航高度和锚点偏移、手机顶栏布局及减少动态效果设置；当时技术正文与数据脚本保留上传版本。后续内容按下面的来源与维护机制更新，保留教学示意、路线图与送样/量产的区分。

`gpu-memory/assets/research-map.json` 保存型号、难点、架构/产业导览、来源与补充事件。`scripts/build_gpu_research.py` 生成首页、新入口、全站导航、相关页路径、资料附录与检索索引；其他技术页正文仍可直接编辑，`IA`标记内的内容由脚本更新。运行 `python3 scripts/build_gpu_research.py` 后，再运行 `python3 scripts/check_gpu_research.py` 和 `python3 scripts/build_gpu_research.py --check`。检查覆盖来源引用、日期、表格列数、唯一锚点、跨页链接与检索目的地；不能替代原文审稿。

学习清单由原包脚本保存在浏览器 `localStorage` 的 `atlas-*` 键中，不发送到服务器；存储受限时仍可阅读、搜索和计算。外部资料链接仅在主动点击时访问。

维护目录 `gpu-memory/`，新增页面时保留本地资源的相对地址及返回导航。GitHub Pages工作流复制整个目录，公网验证逐文件检查HTTP状态、HTML类型和内容与提交一致。`scripts/test_gpu_memory.py [网站根地址]` 检查三处入口、五主线导航、型号筛选与深链、12页桌面/手机布局、图谱、检索、时间线、词典、算术工具、返回主站和存储受限情况。

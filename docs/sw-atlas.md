# 申万一级行业全景

产业链总览默认入口：\`atlas.html\`。按申万2021版31个一级行业提供可搜索目录；每个行业有稳定直达链接，例如 \`atlas.html?sw=801780\`（银行）。801xxx在页面上是一级指数代码，不是行业分类代码。四个阅读分组由本站编排，不是申万额外分类层级。

既有化工、家电、电新、医药·创新药内容通过原 \`?industry=\` 链接保留，基础化工/家用电器/电力设备/医药生物的全景页也提供深入入口。医药生物覆盖范围比创新药大；综合行业按资产组合与治理研究，不虚构单一产业链。

## 内容与证据

- \`assets/sw-atlas.json\`：31行业正文；通用专业机制为独立整理，来源的具体支持范围与文档日期分项列出。
- \`assets/sw-atlas.js\`：目录搜索、阅读分组、独立阅读器、行业内搜索、直达及浏览器历史。银行、非银金融、综合先看方法与资金/资产关系；各行业链条、指标和方法标题及内容分别组织。
- \`assets/sw-atlas.css\`：响应式目录与阅读布局；原行业样式不重写。
- 名单校验依据：已读取的 [Tushare申万分类文档](https://tushare.pro/document/2?doc_id=181) 中部2021版表。原申万分类下载页超时、原修订PDF返回403，未标记为已读取。没有将文档末尾28行业旧版接口示例当作2021版数据。
- 一级行业表不包括独立“仓储物流”；物流属于交通运输。完整保留综合、美容护理、环保、煤炭和石油石化。

每个行业包含至少3条业务链或资金/资产关系、5项带口径与误读的指标、2种有支持与反证条件的方法、3个技术或结构性议题，以及行业陷阱与资料依据。技术成熟度是定性研究判断，不是逐项公司尽调或实时热点排名；政策文件不能证明量产、付费、盈利已兑现。读过正文与核验入口分开显示，企业自述不视作独立交叉验证。没有接入实时行情、伪造当前数据、编造研报出处或复制整篇研报。

## 检查与发布

开发环境在本轮不可用，因此通过GitHub原生接口准备同一源状态，在独立检查分支运行检查，成功后才快进main触发Pages。没有将本地浏览器检查冒充已完成。

\`node scripts/test_sw_atlas.cjs\`检查正式31行业名单/指数代码、唯一性、字段完整性、指标口径、反证字段、资料引用与JavaScript语法。

\`python3 scripts/test_sw_atlas.py\`在Playwright浏览器中遍历31行业、目录和行业内搜索、阅读分组、资料锚点、直达/刷新/前进后退；逐一检查320和390px阅读布局、移动大纲及原专题入口。服务地址可作为参数，支持公网检查。

Pages流程先做完整内容与浏览器检查，再保留原指标研究检查、发布、逐文件公网SHA-256验证与公网阅读器交互检查。旧测试改为显式访问化工入口以适应新的默认全景目录，浏览器路径使用Playwright自身已安装的Chromium，保留原行业回归场景。

## 分类与独立审稿修订

四组行业内容由独立审稿人抽查。已修正水务在申万2021版归环保的边界，公用事业主链不再混入供水；明确生活用纸归美容护理。原油与炼化、电网设备与电力运营、医药全行业与创新药专题等研究边界分别注明。新增环境治理质量负荷、持续达标与监测完整性的指标，避免用平均浓度替代污染物削减或全天合规。

# 申万一级行业全景

行业研究默认入口：`atlas.html`。按申万2021版31个一级行业提供可搜索目录；每个行业有稳定直达链接，例如 `atlas.html?sw=801780`（银行）。801xxx在页面上是一级指数代码，不是行业分类代码。四个阅读分组由本站编排，不是申万额外分类层级。

既有化工、家电、电新、医药·创新药内容通过原 `?industry=` 链接保留，基础化工/家用电器/电力设备/医药生物的全景页也提供深入入口。医药生物覆盖范围比创新药大；综合行业按资产组合与治理研究，不虚构单一产业链。

## 按行业合并指标跟踪

主导航现在仅保留“行业研究”和“日常研究”。基础化工（801030）、家用电器（801110）、电力设备（801730）读者页内有可展开的“指标跟踪”，也支持 `#sw-monitor` 直达。原有模拟图表、CSV、待采集清单、教学计算与电新历史数据保留，数据类别与来源边界逐项标记；其他28行业未虚构看板。原 `?industry=` 深度页同样可以打开对应指标跟踪。

`index.html` 为旧入口兼容页：默认转到行业目录，旧行业查询转到对应申万行业的指标跟踪；医药转到医药生物研究正文。`industry-dashboard.html` 是保留原功能的渲染文档，通过 `assets/industry-monitor.js` 接入行业正文，`assets/dashboard-embed.js` 负责自适应高度和站内跳转。IntelliUI BETA 与四个工具入口归入 `daily.html#daily-tools`。

## 研究正文与证据

行业页先呈现连续机制分析，再接教学推演、真实披露案例和可执行研究路径；原产业链、指标与方法卡片保留在后部速查。章节按行业实际矛盾组织，包含需求与供给滞后、利润分配、现金/资本约束、技术经济性和估值如何接回经营。正文的目的，是展示如何从事实走到解释以及哪里仍不能识别因果，不以覆盖数量或字数代替研究质量。

历史案例逐项列出报告期、原文件链接、印刷页/PDF页或网页章节。年报摘要、债券年报和年度业绩公告按真实文档类型标注，不统称完整年报。同比与会计分解不等于因果识别；产品表的内部抵销、少数权益、税前/归母、期末/平均等边界单列。模型假设与实测事实分开显示。

每行业教学模型提供独立算术表达式，由安全AST解析器复算；不会把教学参数作为行业数据。来源仅支持其明确读取范围，独立机制章节可以无直接来源标记，不用不相关政策作背书。

## 数据与维护

- `assets/sw-atlas.json`：31行业正文；通用专业机制为独立整理，来源的具体支持范围与文档日期分项列出。
- `assets/sw-atlas.js`：目录搜索、阅读分组、独立阅读器、行业内搜索、直达及浏览器历史。银行、非银金融、综合先看方法与资金/资产关系；各行业链条、指标和方法标题及内容分别组织。
- `assets/sw-atlas.css`：响应式目录与阅读布局；原行业样式不重写。
- 名单校验依据：已读取的 [Tushare申万分类文档](https://tushare.pro/document/2?doc_id=181) 中部2021版表。原申万分类下载页超时、原修订PDF返回403，未标记为已读取。没有将文档末尾28行业旧版接口示例当作2021版数据。
- 一级行业表不包括独立“仓储物流”；物流属于交通运输。完整保留综合、美容护理、环保、煤炭和石油石化。

每个行业包含至少3条业务链或资金/资产关系、5项带口径与误读的指标、2种有支持与反证条件的方法、3个技术或结构性议题，以及行业陷阱与资料依据。技术成熟度是定性研究判断，不是逐项公司尽调或实时热点排名；政策文件不能证明量产、付费、盈利已兑现。读过正文与核验入口分开显示，企业自述不视作独立交叉验证。没有接入实时行情、伪造当前数据、编造研报出处或复制整篇研报。

## 检查与发布

初版因开发环境不可用，曾通过GitHub接口与远程检查发布。本轮环境恢复后，在本地核对原始资料、复算模型和执行浏览器交互检查，再提交与发布。

`node scripts/test_sw_atlas.cjs`检查正式31行业名单/指数代码、唯一性、字段完整性、指标口径、反证字段、资料引用与JavaScript语法。

`python3 scripts/test_sw_atlas.py`在Playwright浏览器中遍历31行业、目录和行业内搜索、阅读分组、资料锚点、直达/刷新/前进后退；逐一检查320和390px阅读布局、移动大纲及原专题入口。服务地址可作为参数，支持公网检查。

Pages流程先做完整内容与浏览器检查，再保留原指标研究检查、发布、逐文件公网SHA-256验证与公网阅读器交互检查。旧测试改为显式访问化工入口以适应新的默认全景目录，浏览器使用GitHub Ubuntu 24.04镜像预装的Chrome，由Playwright驱动，保留原行业回归场景。

## 分类与独立审稿修订

四组行业内容由独立审稿人抽查。已修正水务在申万2021版归环保的边界，公用事业主链不再混入供水；明确生活用纸归美容护理。原油与炼化、电网设备与电力运营、医药全行业与创新药专题等研究边界分别注明。新增环境治理质量负荷、持续达标与监测完整性的指标，避免用平均浓度替代污染物削减或全天合规。

## 算术、引用与编辑审阅

`python3 scripts/check_sw_research.py`核对正文引用、案例定位、表格结构、模型/实测分离，并独立重算教学及已提供的案例算式。这些检查验证内部一致性，不验证市场观点。编辑审阅另行对照原件，已修正库存周期术语、文件页码、资本损失重复扣减、CET1工具范围、同比归因跳步等问题，并补充宁德、招行、紫金、伊利等实际利润/现金分解。

资料摘录、临时PDF和审阅草稿仅留在本地工作目录，不随网站发布；网站保留原始公开文件链接和定位，避免将原件镜像或大段转载误作自有研究。

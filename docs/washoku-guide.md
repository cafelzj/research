# 日料菜单预制风险判断

入口：`washoku.html`，归入“日常研究”，与法国专题通过专题导航相互切换。数据、界面脚本和样式分别在 `assets/washoku-data.js`、`assets/washoku.js`、`assets/washoku.css`。纯静态，无需构建、后端或模型。

## 口径

本页以中文日料店的常见菜单为参考，60道分为8类，包含传统、居酒屋、连锁和融合菜式，不是日本料理完整分类或餐厅抽样调查。

主标签以红黄绿表示明确的定性判断，而不是仅给出提问方向：

- **高风险（26道）**：主要成品或成型半成品可以替代门店主要制作，最后只需解冻、复热、煎炸或组合。重点包括成品凉菜、熟鳗鱼、厚烧蛋、裹粉成型炸物、章鱼烧、煎饺、肉丸和外购甜品。
- **中风险（23道）**：关键配料或预加工值得查，同时现场制作也直接；不把咖喱块、汤汁、面体等基础组件一律算整餐成品。
- **低风险（11道）**：按整菜预制口径降低核查优先级，如生鱼刺身、现握生鱼寿司、部分现场烤物与涮锅；不是无外购配料、完全自制或食品更安全。

适用假设为普通综合日料店，不针对已取得制作证据的具体门店。判断依据是主要工序外移程度、冷链和复热路径、替代的技术或劳动；厂商商品作佐证，不从商品存在推导市场使用率。每条 `risk` 独立保存 `level`、`target`、`reason`，避免用原供餐路径自动套风险。蒲烧鳗鱼、鳗鱼饭、鳗鱼握寿司的高风险主要指鱼料，米饭和寿司组装单独判断。天妇罗、煮鱼、炖牛肉、茶碗蒸等保留中风险，不把门店批量备料本身算外购。

首页五组重灾区来自 `hotspots`，三档说明来自 `riskLevels`。类别内高风险优先，保留菜品分类。支持一键只看高风险、组合风险/分类/来源按钮筛选；风险图例和重灾区跳转会清空旧筛选，避免被之前的条件意外隐藏。风险支持 `?risk=high|medium|low` 深链、浏览器历史以及CSV导出。点击“显示全部菜品”恢复全部60道。

供餐路径降为中性辅助标签，解释判断涉及的工序：

- 整品/成品：可能采购已完成主要制作的熟品或即食品，门店复热、解冻或摆盘。
- 成型/裹粉半成品：清理、调味、成型、裹粉、预炸等工序可能在外部完成，门店再煎炸熟制。
- 成品配料参与：整道菜可以现场组装，熟鳗鱼、鱼糜、调味海鲜、面体或酱汁等组件单独核实。
- 关键在现场操作：切配、调味、煎烤等可以在门店完成，仍不能从菜名反推出此前原料处理。

风险等级是编辑判断，不是门店查实结论，也没有使用率、概率或质量分数。冷冻不等于整菜预制，门店提前备料不等于工厂成品，现煎现炸也不等于从头自制。成品冷菜、甜品、速冻面米、调味品和中央厨房模式与具体监管定义需分开；本页不作法律归类。

“炸物与热小食”包括煎饺和章鱼烧，已明确不代表它们一定油炸；“蛋料理与煮物”包含玉子烧和茶碗蒸，避免把玉子烧误写成蒸蛋。

## 已读取的直接资料

12个厂商页面支撑13道菜的相关商品例证。URL、用途范围、市场、局限和读取时HTML的SHA-256在数据文件中。源页面的市场可能是日本或北美，家庭用或餐饮用；不据此推断中国门店的采购、使用率或法规分类。商品的具体生熟和加热要求以具体标签为准。

- Ajinomoto Foodservice：成型鸡肉蔬菜饺子，产品码6440083及使用方式；不把一个SKU推广为所有煎饺都生制或全熟。
- Nissui：冷冻章鱼烧品牌页及鱼糜配料品牌页；只证明相应商品存在。
- Azuma Foods：芝麻调味海藻、芥末章鱼产品；原页列有用途和调味信息。
- Kewpie：餐饮用土豆沙拉与玉子烧商品目录。
- Nichirei：明确标注生IQF、未加热的唐扬鸡SKU，以及可乐饼商品目录。该例说明半成品到店后熟制与全熟品复热不同。
- TableMark：冷冻讃岐乌冬特设页；证明面体供给，不等于汤底、浇头或整碗面的制作结论。
- 川口水产：蒲烧加工流程，说明烧制后冷冻真空包装、保管与供货。
- 山田水产：商品信息同时列有真空包装蒲烧与冷冻鳗鱼饭，支持“只采购鱼料”与“采购整餐”分开研究。

未把维护页、搜索零结果页、未读正文的图片型PDF或无法访问的链接当成已核验来源；未复制厂商商品照片。插画为本页SVG图形，非菜品实拍。

其他47道卡片的风险判断来自工序与供餐逻辑推断，未绑定直接商品例证，已在卡片上标明。对商品路径的整理不能替代门店调查。高风险不必然有直接商品来源，来源与风险是独立维度；没有来源时不能冒充已核验商品或市场统计。

## 只读浏览与导出

按用户要求移除收藏、清单填写、备注、笔记导出及文字搜索。页面不含input、textarea、select或form；保留风险/分类/路径/商品例证按钮、来源和CSV下载，不再读取或写入收藏/笔记存储。

筛选菜单CSV包含网页风险、判断对象、理由和依据类型。分类、路径、风险以及推荐菜定位仍支持URL参数；定位条件以文字显示，可点击“显示全部菜品”清除。扩展菜品需追加明确的定性判断及依据，不得添加未经调查的门店定论或“预制概率”。

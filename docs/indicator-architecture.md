# 指标研究台：分类、检索、关系与数据处理

入口：`indicators.html`（IntelliUI 的“指标研究台”）。公开站点内置人工功能演示，原 Excel、全量目录、SQLite 和逐条审计结果默认只在本地保存；固定汇总审计与研究说明可在网页阅读。上传到浏览器的 JSON 不发送服务器、不持久存储；本地服务自动加载其私有索引。程序不需要模型密钥。网页手册见 [指标研究手册](https://cafelzj.github.io/research/indicator-guide.html)，或在研究台切换“研究说明”。

## 1. 先读清这份 Excel

工作表“全行业指标”有两行标题、一行示例；排除示例后有 **62,241 条行业引用记录、61,781 个独立 code、21 个原始行业标签**。其中460个code各出现两次，全部只是行业归属不同，其他属性一致，应该建一个实体并保留多行业标签，而不是报为属性冲突。原表没有观测日期、数值时间序列或 Excel 公式。

家用电器47,650条，占引用记录约76.6%。不能让条目多的行业在模糊检索中自动压过其他行业。原始行业也并非严格经济分类，故保留原标签，与规则推断的研究角色并列呈现。

按原始行计，健康标记包含停更27,451、预警1,041、空值6；单位空值709。只有127条实际别名，联想查询列全空。`@,@`是约定分隔符，别名内部的逗号可能是产品规格，不能按逗号拆开。所有数字是本次文件的目录审计，不能解释为实时数据健康或经济异常。

可发现月度名称与年频、比率名称与数量单位等疑点，但程序只标记待核验，不擅自改值、改单位或改频率。代码前缀不作为“必然是衍生指标”的证据。

## 2. 用多维分类，避免一棵大树装所有对象

- **身份层**：命名空间、原始 code、唯一 id、来源；相同代码且属性一致时允许跨行业多标签，属性冲突保留多条。
- **对象层**：产品、规格、品牌/企业、渠道、地区。纯/聚合 MDI、轻/重碱、线上/线下、总量/品牌不可当同义词。
- **研究层**：价格与成本、供给与产能、需求与消费、库存与物流、进出口与贸易、盈利与财务、宏观与政策，以及未分类。
- **统计层**：频率、单位、当期/累计/期末、原值/同比/环比/占比。
- **证据层**：原行业/原名称/原别名、规则推断、候选关系、人工核验、可执行公式，各有不同状态。

当前角色由保守名称规则生成，地理词典识别也有边界；未知保留未知，不默认为全国。未实现通用实体抽取或对全行业产品规格的完备知识库。

## 3. 数据契约

```text
Catalog: schema_version, meta, records[], audit, relations[]
Record: id, code, name, industry, industries[], frequency, unit,
        source, health, aliases[], role, transform, base_name,
        geography, source_row, source_rows[]
Relation: source, target, type, status, reason, formula_hint?
Observation CSV: series_id,date,value,unit,frequency,region,source,coverage?
```

meta 记录文件名、SHA-256、原工作表、排除示例、行数/实体数、关系政策及是否有观测。SQLite 保存原始属性与索引；JSON 是前端可本地导入的同一契约。缺失单位置空，不能随意从指标名猜一个单位后当已验证。

role、geography、transform、base_name 来自规则，不是人审过的字典。原字段不被覆盖。衍生值另存 output_value/output_unit 与质量标记，不覆盖原 value。

## 4. 检索与自然语言

顺序为：Unicode/标点归一 → 代码/全名/登记别名精确检索 → 结构化口径提取 → 约束过滤 → 名称实体与受控同义词匹配 → 排序与消歧。

前端 `assets/indicator-search.js` 直接索引浏览器当前目录；后端 `indicator_lab/search.py` 提供SQLite与本地HTTP检索。两者都由规则解析、不是大模型，也不是向量相似度。共同契约是“不静默放宽明确口径”，但解析词典分别实现，不保证任意自然语言句子得到完全一致结果。核心语义边界有真实指标回归题；遇无法解析的表达，应澄清或返回空候选。

规则包括常见中英文缩写、已有别名、地区、频率、同比/环比/累计、否定口径、纯/聚合、线上/线下、来源等。代码与全名优先并不意味着用户的额外筛选可被忽略；筛选与自然语言冲突必须显式反馈。

- CPI不能因为包含字符就匹配CCPI；SCFI不能偷换CCFI。
- DMC可能表示硅氧烷或碳酸二甲酯，应并列消歧。
- LFP正极和LiPF6电解液盐不能合并。
- 查均价不能默认用零售额、零售量、份额或增长率代替。
- 同名不同来源保留独立code，解释每条来源、频率和单位。
- 原始健康“正常”不等于最近有数据；停更记录仍可被检索，用状态筛选控制。

未来接入模型时，应只允许模型生成受约束 QueryPlan（对象、维度、否定约束、命名空间、候选id），复用现有过滤与消歧，不允许模型直接执行SQL、任意URL、公式字符串或给数据编造说明。模型密钥只放后端。向量召回可以增加候选，不能绕过硬口径检查。

## 5. 三类关系与公式审批

1. **同名候选**：名称相同但代码/来源不同，用于消歧，不自动合并。
2. **派生候选**：名称主体、来源、频率、识别地区与相关口径兼容。只说明“可能相关”；同比可能是增长率，也可能涉及百分点变化。份额与存量不可自动累计求和。
3. **研究假说**：如纯碱→玻璃、家电量价→收入、集装箱运力→运价。研究路径用于组织问题，方向、系数、时滞均未实证。

**可执行公式依赖**是另一种审核后的关系，需要精确输入series id、表达式定义、单位换算、时间对齐、缺失策略、系数与版本。当前目录不存在已验证公式依赖。名称“价差”不足以推导系数，不能拿名称相似的两条序列直接做减法。

前端关系按需展示邻居，避免把62k指标画成不可读的全局毛线团。产业链路径节点提供明确查询，回到同一个检索器核对候选。

## 6. 数据处理与异常分层

目前可执行的 CSV 流程只接受已明确身份/单位/地区/来源的**月度数据**，不隐式重采样日周季度，也不插值或补零。支持 identity、yoy、mom、cumulative_to_period。

- 同比找同一序列上年同月，环比找前月；缺基期、零基期保留null和原因。
- 累计转当期仅在显式声明flow后执行，不跨年相减；1月累计可等于当期，遇合并1–2月不能拆月。
- 重复期不任选一条；同序列混单位、地区、频率、来源拒绝处理。
- 保留输入行号、原始日期、原始值和基期行。负基期、负当期或修订作为复核线索，不自动当错误删除。
- 非有限输入和计算溢出产生质量信息，不输出伪数值。

异常分四层：元数据缺失/冲突 → 计算质量（基期、重复、恒等式与口径）→ 统计候选 → 经济解释。`quality_candidates` 对真实月度差分的过去窗口做MAD复核，不用未来值；历史不足或MAD为零不假造确定的异常分数。统计候选不是因果、投资建议或可靠拐点。

修订版本、发布时点/可用时间、单位换算、跨频对齐、价差/毛利公式、季节调整与实证滞后因果检验仍需后续接入与专项验证，不伪称已完成。研究回测必须区分观测期与当时可知的发布日期。

## 7. 远程指标与安全

公开前端有10项已核对元数据的World Bank公共年度指标（GDP、CPI通胀、进出口、制造业、中央政府债务、教育、电力等），在本地匹配目录后，用户点击才向固定World Bank API读取选定国家的数值。国家、单位和定义明确显示；null不是0；接口错误不回退演示值。原私有目录不会被上传。

本地Python另有World Bank受控连接器，可按代码或英文元数据检索，`serve --allow-remote`才开放远程API。它与前端10项中文登记目录覆盖范围不同。两者都没有接入Wind/彭博/付费行业库；Excel“来源”列不是API地址、更不是授权证明。扩展供应商需实现独立adapter、配置服务端凭据及授权范围，不能放入前端代码。

服务只绑定127.0.0.1，限制Host/Origin，只读API与静态白名单；拒绝路径逃逸、任意URL代理与非白名单远程目标。构建产物在网站目录外；无目录浏览、无前端密钥、无自动对外写入。公开GitHub Pages只承载前端，不能托管Python/API；完整目录以本地服务或本地JSON导入使用。

## 8. 运行与验证

见 `indicator_lab/README.md`。典型流程：

```sh
python3 -m pip install -r indicator_lab/requirements.txt
python3 -m indicator_lab build --input /私有路径/指标.xlsx --output /私有路径/catalog.sqlite
python3 -m indicator_lab export --db /私有路径/catalog.sqlite --output /私有路径/catalog.json
python3 -m indicator_lab serve --db /私有路径/catalog.sqlite --port 8765
python3 -m indicator_lab prepare --input observations.csv --output result.json --operation yoy
```

回归验证覆盖引擎导入/口径/序列计算/远程安全、浏览器检索/同名/同义/目录导入/错误状态/手机宽度；全量验收使用本地私有目录。测试中的演示观测不作为生产研究事实。


## 9. 固定在网页中的研究说明

研究台的 `#view=guide` 与独立的 `indicator-guide.html` 共用 `docs/indicator-guide-content.html` 内容源，审计汇总来自白名单字段的 `assets/indicator-audit-summary.json`，运行 `python3 scripts/build_indicator_guide.py` 生成两处静态正文；`--check` 用于 CI 检查同步和计数核对。生成器不读取或发布私有工作簿、目录、SQLite或逐条问题记录。

说明分为文件审计、分类、检索、关联、异常、处理流程、能力状态和使用八章。原文件计数为固定快照，研究台当前目录的统计另算；缺单位709引用行与508实体明确分开。即使未导入完整目录或禁用脚本，手册正文仍可阅读，独立页支持移动大纲与章节链接；打印会临时展开详细定义并恢复原阅读状态。

工具内案例链接使用当前已加载目录，按示例清空额外筛选和设置范围，不导入、替换或持久化目录。`#view=search&q=...&scope=local|remote` 是预设检索，`#guide-章节名` 是说明锚点；查询写在片段中，不随页面请求发送服务器。浏览器返回恢复对应视图；完整目录的内存生命周期保持原约定。

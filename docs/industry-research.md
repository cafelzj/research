# 家电与电新研究模块

产业链与看板沿用现有入口，通过 `?industry=appliances` / `?industry=electrical` 切换；化工仍为默认行业。内容在 `assets/industry-content.js`，共享渲染与只读研究内容在 `assets/industry-research.js`，样式单独维护。

## 当前内容与研究边界

家电：5条链、12项指标、5套研究方法、4个历史复盘题、6项技术、16个术语。电新：6条链、12项指标、5套方法、4个复盘题、8项技术、18个术语。共同提供四周学习路径、研究方法和只读指标观察框架。按用户要求移除笔记、观察录入、证据记录和学习勾选。

这是教学研究框架，不是已完成的券商深度报告。宏观统计、政策原文、公司定期报告、IEA及IRENA报告仍因来源访问受限而未逐条核验，界面已标注；历史事件内容仅为待核验线索与复盘方法，没有伪造数值、公司结论或回测收益。尚无当前行业评级或自动行情。

## 已读取资料（2026-10-23）

- SAM：官方项目仓库README、LCOE帮助正文。核对能源项目性能/财务模型定位及真实/名义币值、模型财务边界；未实际运行SAM。
- EnergyPlus：官方项目仓库README。核对全建筑能耗与用水模拟工具定位；未将其当家电销售或某型号性能测试报告。
- OWID energy-data：README、固定提交CSV和字段字典，提取中国2015—2024年 `solar_electricity`、`wind_electricity`、`electricity_generation`，单位TWh。字段字典列出Ember和Energy Institute上游来源，未单独重新核验每个上游原始发布。

OWID固定提交：`f8de88a4f6f9cab44f1cf606047cbd6c4414042c`。页面中提供原CSV、字典和复算表，发电占比为（风电+光伏发电）÷总发电量；不用装机功率作分母。README提示数据迁移与一次能源计量方式变更，本页历史图始终使用单一快照，不拼接新序列，也不把电量增长当制造盈利增长。

## 待补充的真正深度调研

1. 按已保存的环境网络草稿放行官方统计、协会、政策、巨潮、IEA与IRENA来源。
2. 逐条记录政策原文、发布日期、适用对象与有效期，核对每个历史复盘事件。
3. 家电选择白电与小家电各至少一家、电新按各商业模式选对照公司，读取三年年报及最新已披露报告；核对分部、量价、存货、应收、减值、现金流与会计政策。公司选择仅用于学习，不构成推荐。
4. 填充真实指标前先确定单位、地区、频率、发布时间与样本；区分收费数据和公开数据，不能用抓取绕过订阅。
5. 为政策和财报事实增加精确文档/页码引用，复核通过后才更新单项来源状态。不能把仅访问首页当作事实核验完成。

## 运行与验证

在仓库根目录启动 `python3 -m http.server 8000 --bind 127.0.0.1`，执行 `python3 scripts/test_industries.py`（Python Playwright + 系统Chromium）。测试覆盖两行业与化工切换、内容与搜索、无笔记或采集表单、只读研究步骤、教学计算、手机大纲/布局、返回导航及无存储依赖。可传其他静态服务地址。

研究页面不再读取或写入个人笔记、学习完成度或采集记录。保留搜索、行业切换和教学情景计算；暂无已核验的当前指标时显示缺失，不要求用户录入补齐。

入口：[大模型演进研究](https://cafelzj.github.io/research/llm/index.html)。专题归入“日常研究”，日常首页、日料与中餐专题导航均提供入口，全站“行业研究 / 日常研究”的层级保持一致。

## 研究范围

证据核验截止为 **2026 年 11 月 14 日**，主发布时间线从 2026 年 1 月 1 日开始，重点覆盖 Kimi、GLM、Qwen、DeepSeek 的主要模型与重要 API 变化。其他中国与海外主要厂商为有明确范围的选编，不声称穷尽所有社区微调、专项生成模型、区域上架或补丁。

架构章节为帮助理解已发布模型而追溯必要背景：普通残差、Hyper-Connections、混合注意力等部分研究早于2026；mHC首稿为2025年12月31日，2026年修订与模型采用不改写为首次提出。模型发布、论文公开、API可用与权重提交分别记录，不能互相替代。

## 来源与判断如何分开

优先使用官方公告、作者论文、模型卡、官方代码和 API 日志。官方内容能证明其发布与所作宣称，不自动证明所有性能倍数或业务效果；独立评测有其任务集、版本、预算和不确定性边界。解释性推断与教学假设明确标注，本轮未重新训练模型、复跑全部 benchmark 或采集付费调用账单。

维护时逐条检查以下区别：

- 公告、API上线、论文、预览、正式版、权重记录、接口/产品系统升级与退役不混算。
- 只核到月的事件保留月粒度；不同地区/产品渠道的日期分别列出。权重仓库初始提交可能早于公开权限变化，不直接认定为首次公众可下载时刻。
- 总参、激活参数、查表/条件记忆参数和权重仓库统计口径分开；输入预填充与输出解码的不同计算路径不误写成两款模型。
- 跑分保留测试集版本、子集、指标、harness、工具、思考与重试预算；百分点与相对增幅分开。
- KV缓存节省不等于整模型显存同比下降；理论位宽、输出速度、标准token价与每成功任务总成本分别核算。
- 开放权重不等于无条件商用；不同分支许可证、服务促销、限时预览与变化中的API路由按具体版本核验。

## 动画与算例的边界

逐步动画用简化的token、向量、分支、专家或缓存演示信息流。它们不是生产模型内部轨迹、真实注意力权重、GPU性能测量或完整训练仿真；分支与专家的图示也不代表预先指定的职业分工。人为数值算例与厂商/作者实验结果分开。

播放、暂停、步进和重置等控制用于学习过程，不改变正文事实。遇到减少动态效果设置时，应保持可阅读、可手动理解；动画之外仍需文字、公式与图例说明。

## 公开内容与工作笔记

`work/llm-2026/` 保留本轮搜集、交叉核验与生成报告过程中的工作材料，不随 GitHub Pages 发布。网页使用的研究正文、术语、公开来源链接及专题静态资源会发布，用户能够在网页中阅读研究和回到原始证据；“工作笔记未公开”不等于隐藏网页结论的依据。

新增材料应先整理来源、日期类型、支持范围与反证，再更新统一内容源和静态输出；避免直接在多个生成页面分别修同一事实。发布前检查来源和内部锚点、正文与术语一致性、动画控制、320/390px移动布局以及原日常研究入口。按仓库发布流程提交、部署，并等待公网文件校验与浏览器检查通过后再确认上线。


## 构建与验证

公开正文源位于 `llm/content/`。修改后运行 `python3 scripts/collect_llm_research.py` 生成时间线，再运行 `python3 scripts/build_llm_research.py` 生成10页。两脚本均支持 `--check`；`check_llm_research.py` 校验日期、证据、术语关系、锚点与教学契约；`test_llm_research.py [站点URL]` 验证浏览器交互、响应式阅读、无脚本正文与减少动态效果。KaTeX 0.16.22 本地托管，npm SHA-512核对记录与MIT许可在 `llm/assets/vendor/katex/`，CSS仅保留WOFF2字体来源。GitHub Pages复制整个 `llm/`，发布后逐文件核对SHA并复跑公网交互。

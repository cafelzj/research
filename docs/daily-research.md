# 日常研究：法国事件与欧洲结构指标

入口 `daily.html`；所有主导航已接入。首个专题以用户提供的百度百科「10·17法国暴力骚乱事件」条目为线索，研究法国与10个欧盟国家中的其他9国的结构背景。

## 事件核验边界

用户表示关注近几周巴黎事件，随后提供百科链接。该页面被环境目的地策略拦截，正文和引用报道未读取。URL标题仅提供10月17日，不能据此推断年份、经过、参与人数、伤亡、诉求或直接触发因素。页面明确保留待核验状态，未套入2023年退休改革抗议或城郊骚乱，未编写新闻摘要。

需要放行原页和其引用报道后，核实年份与用户所指是否对应，再以巴黎/警方公告与至少一份独立报道交叉核验。百科不是新闻事实的独立验证。国家级经济指标不是事件现场或参与者数据。

## 指标与样本

样本固定为法国、德国、意大利、西班牙、荷兰、比利时、波兰、瑞典、奥地利、丹麦。这是选定国家样本，不是欧盟全部成员，也未计算欧盟加权平均。

- IMF：一般政府总债务/GDP、一般政府财政余额/GDP。不是中央政府债务，不将未确认未来养老金承诺叠加进债务。
- WDI：公共教育支出/GDP、总失业率（ILO模型估计）、CPI通胀、基尼、65岁及以上人口比例。不是教育占财政支出比例、青年失业率或老年抚养比。
- 公共养老金、公务员专门退休制度：仍缺10国可比原始数据，显式保持空值，不拿退休年龄、替代率、一般养老金或未经核验的二手数字替代。

每张地图内同年，年份可手动改变。切换指标时采用该指标最近完整样本年：债务/财政/失业/通胀/年龄为2024，教育为2022，基尼为2021。选择2023基尼时允许部分国家缺失；不带入另一年补齐。数据仅覆盖2018—2024，整理/读取日2026-10-24。

## 数据来源与可复核性

`assets/daily-data.js` 保存数值、观测状态、固定Git提交、文件URL、SHA-256与指标说明。

1. IMF第三方镜像 `mitsuoxv/imf-weo`，提交 `4c9ec091cab0538110839854f82f2a8ca65d3cb0`。已读取README、R处理脚本、`data_2610.rda` 与元数据。脚本指向2026-10-13的IMF WEO下载文件；未访问IMF原始下载，版本属于镜像可追溯线索。
2. 逐行要求 `year <= lastactualdate`，保留PT单位与scale=0的历史行，排除预测。没有把较旧IMF镜像内对未来年份的预测当已发生事实。
3. WDI第三方镜像 `datasets/world-development-indicators`，提交 `4ebec5a2273f531ba238a34dbe440394dc5a6c4b`。已读取所用CSV与每个指标的datapackage元数据。尚未回查官方API或逐国调查。基尼还需复核收入/消费、税前/税后与调查定义；ILO失业率保留模型估计标记。
4. Natural Earth 1:110m Admin 0轮廓，来自固定提交的公开GeoJSON，公共领域。仅提取欧洲背景国家及ISO3名称；地图为简化经纬度投影。法国只显示欧洲本土等可见区域，统计范围以原指标为准。巴黎点是城市定位，不是事件现场坐标。

镜像数据的实际数值和处理可审计，不等于已获得官方背书。2026版本可能修订早年数据；事件年份和信息公开时间未明确前，不可作为“当时就能预测”的事前证据。

## 功能与扩展

- 地图、表格、排序与国家详情共用同一数值查找；颜色只编码大小，非好坏或风险评分。样本中位数是未加权的10国有效观察中位数，不称欧盟平均。
- 地图支持鼠标、Enter/空格键和等价国家选择框；导出当前年份的CSV或含标题、单位、版本边界的独立SVG。
- 按用户要求移除“把每天的观察，留成证据”整节、笔记表单、保存视角及私人笔记导出，不再依赖浏览器存储。地图指标、国家、年份与排序仍可选择，CSV/SVG导出保留。
- 后续增加指标，在数据文件追加明确单位、定义、局限、来源、逐年ISO3观察和默认完整年即可。国家扩展时需同时补几何与统计范围。新增专题应使用单独 `topicId` 组织只读内容；当前没有实现通用多专题后台或实时更新。

## 验证

启动静态服务后运行 `python3 scripts/test_daily.py http://127.0.0.1:8001/`。覆盖十国ISO连接、键盘地图、年份切换、缺失不填零、预测截止、CSV/SVG导出、无笔记/保存视角表单、URL校验、手机大纲与六页导航。

数值审计：安装临时开发依赖 `rdata==1.0.0` 后运行 `python3 scripts/check_daily_snapshot.py`。该脚本从固定URL下载并验证哈希及逐行提取，不修改应用文件，也不把镜像校验升级为官方核验。前端不需要Python、R或新包。

GitHub Pages流程和公网校验脚本均包含daily.html及全部assets。`assets/france-europe-debt-2024.svg`为本次默认债务地图的独立导出快照；更改数据、配色、绘图或来源说明后需从页面重新生成。当前所选指标的SVG也可以从页面导出，包含数据年份与“官方原页待回查”说明。

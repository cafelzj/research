# 知研集 · 行业、数据与日常研究

从日常好奇，到有据可查。汇集产业链分析、数据图表与日常专题研究。

## 栏目结构

四个主栏目采用统一导航：

手机和平板宽度（不超过900px）下，原有四个页面右下角提供按需打开的“大纲”按钮：显示本页主要章节与当前位置，点击章节后跳转并自动收起，可回到页首；跳往折叠说明时会自动展开。支持关闭按钮、遮罩、Escape和键盘焦点操作；桌面端默认隐藏浮动按钮。大纲只导航当前页面，不改动筛选数据或图表配置。

| 栏目 | 入口 | 用途 |
| --- | --- | --- |
| 日常研究 | `daily.html` | 以事件线索组织跨国指标地图、来源核验与研究逻辑 |
| IntelliUI | `intelli.html` | 智能工作区、指标研究台、数据明细与图表制作的统一入口，支持撤销和CSV共享 |
| 产业链总览 | `atlas.html` | 上下游关系、六条工艺主链、分析框架与子行业研究 |
| 行业看板 | `index.html` | 价格、产量、开工率等模拟月度数据的快速观察 |

**IntelliUI** 包含智能工作区（`intelli.html`）、指标研究台（`indicators.html`）、数据明细（`data.html`）、图表制作（`studio.html`）四个子栏目。指标研究台管理目录身份、口径、分类、关联候选和质量；另外三个视图继续共享 CSV 数据，不把指标名称误当成时间序列观测。

智能工作区、数据明细与图表制作共享 `assets/data-core.js` 的数据生成、CSV校验和会话暂存逻辑。数据仅保存在当前浏览器标签页的 sessionStorage 中，刷新和同标签页站内导航后可继续使用，不上传服务器。完整数据与分析筛选快照分开保存，分析一个子集不会覆盖完整数据；关闭标签页后会话结束。存储不可用时明确提示，可通过CSV手动传递。行业看板继续使用固定模拟样本，导入自定义数据的主入口为数据明细。

产业链总览末尾新增[入门术语表](https://cafelzj.github.io/research/atlas.html#glossary)：45个术语分为原料与产品、工艺路线、供需指标、成本与财务、数据与交易口径。每项提供中文名、常见缩写/英文、通俗解释、示例和易混点，可搜索、分类筛选，并返回关联产业链。页顶搜索提供术语匹配入口；无JavaScript时仍可阅读全部定义。内容来源文件为 `assets/glossary.json`，修改后运行 `python3 scripts/build_glossary.py` 更新页面中的静态内容，脚本可重复运行。

首页 `index.html` 为研报风格的交互图表演示，使用模拟化工月度数据，手机单列布局、固定表格首列。原版研究地图保存在 `atlas.html`，首页底部可进入。

支持价格折线图、月度价格对比、产量堆叠图、开工率趋势，以及价格、同比、环比、产量、开工率和产量占比表格。点击价格图例隐藏系列，点击或轻触数据点查看数值，可播放月度走势。

**研究边界：**这是一版研究框架与学习工具。官方宏观统计、政策原文、公司年报、IEA/IRENA报告的逐项核验仍受来源访问限制，页面已分别标注；历史事件部分是待验证的复盘题，不能冒充已完成的深度历史研究或当前行业判断。来源记录与后续核验清单见 [研究说明](docs/industry-research.md)。

## 图表工作台

公网入口：https://cafelzj.github.io/research/studio.html 。从首页导航也可进入。

- 绘图库：**Apache ECharts 5.6.0**，Canvas 渲染。本地托管固定版本，不依赖第三方 CDN；库及 Apache 2.0 许可证位于 `assets/vendor/`，`provenance.json` 记录来源及经核对的 npm SHA-512 完整性值。首页旧看板继续使用原生 SVG。
- 类型：散点图、气泡图、折线图、柱状图、堆叠柱状图、饼图和环形图。
- 映射：可选择 X、Y、气泡大小字段，交换数值坐标轴，修改轴标题、零起点和时间范围，按产品筛选。饼图选择单个月份，避免将不同月份混合为构成。
- 样式：红蓝、紫、绿、蓝、红及自定义主色；圆形、方形、三角形、菱形、圆角方形；点大小、气泡最大直径、平滑折线和数值标签。
- 导出 / 复用：PNG 图像、图表配置 JSON、数据 CSV；配置可重新导入。CSV 必须包含 `date,product` 及至少一个数值列，额外数值列自动成为可映射字段（上限20个）。已知字段单位见网页说明，未知数值列显示原始字段名；可用坐标轴标题补充单位。产品最多15个，最多120个月、1800条记录，CSV 上限2 MB。
- 自然语言示例：`全部产品近12个月气泡图，X轴价格，Y轴开工率，大小按产量，三角形，紫色`、`最新月份全部产品产量饼图`。这是规则解析演示，未连接模型服务。

扩展入口为 `assets/studio.js` 的 `buildOption(config, data)`：数据导入、配置读取与图表生成分开，添加图形无需重写 CSV 解析。新增指标可直接从 CSV 数值列进入；可在 `knownFields` 注册中文名称和单位。气泡面积按所选非负数值缩放，负大小排除，零值不显示；饼图拒绝负值或全零。JSON 只接受工作台支持的配置字段，不执行脚本。

自然语言功能内置术语表与解析报告，展示原句、规范化、配置 JSON 以及未识别片段。新增像素大小、十六进制主色、图例显示/隐藏及顶部/底部设置。子图、分面、双Y轴和未知字段会明确报错并保留原图；当前没有把这些能力视为已支持。[自然语言图表协议](docs/natural-language.md) 说明处理链路、默认值和后续模型接入边界。

同一输入框可询问设置，例如“可以设置哪些参数？”“气泡大小怎么设置？”“图例能隐藏吗？”“支持子图吗？”。本地设置问答按主题读取实际控件、当前配置与当前数据字段，回答范围、适用图形、限制和示例；不会修改图表或调用生成器。答复区可继续选择主题，或“填入生成示例”后发送生成。新导入的 CSV 字段会进入答案。当前帮助为规则与功能说明驱动，未接入开放式 AI；未匹配的问题会说明范围。控件专属参数与自然语言支持的参数会分别说明。

手机访问：优先通过发布后的网站地址使用。聊天附件预览、部分文件预览器可能不执行 JavaScript；首页已内嵌模拟数据的静态图表和表格，此时仍可查看内容，但交互需在支持 JavaScript 的浏览器中使用。脚本避免依赖 `Array.at()`，兼容未提供该方法的手机浏览器。更改内置模拟数据或默认图表时，需同步更新 HTML 中的静态预览。

自然语言输入为本地关键词解析，并未连接大模型。示例：`近6个月甲醇和尿素价格折线图`、`生成近3个月全部产品价格同比热力表`。任意问法需后续通过后端接入模型，不能把模型密钥放进静态网页。

复用数据：从数据明细或图表制作导出CSV模板，替换后导入，基本字段为 `date,product` 和至少一个数值列。日期为 `YYYY-MM`，每个产品每月一行。其他行业可直接添加数值列并使用字段映射；如单位不同，应核对并调整轴标题。看板中同比需要上年同月价格，环比需要上一个自然月价格，缺失显示 `—`。

面向券商行业研究的静态网页，从产业链串联供需、成本、库存、价差与盈利验证。当前优先研究行业，未展开公司推荐。

## 使用

下载本仓库，使用浏览器直接打开 `index.html`。网页包含内嵌样式和 JavaScript，无需安装依赖或构建，也可放到静态网站服务器。

GitHub 的文件浏览页面显示源码，不直接运行网页。已加入 `.github/workflows/pages.yml` 自动发布流程。

首次部署需要在仓库 Settings → Pages → Build and deployment → Source 选择 **GitHub Actions**。然后在 Actions 中打开 `Deploy research atlas to GitHub Pages`，使用 Run workflow 启动，或重跑先前失败的部署。部署成功后的预期访问地址为：https://cafelzj.github.io/research/ 。以 GitHub Pages 返回的实际地址为准。

此后每次推送到 `main` 都会自动发布。站点发布 `index.html`、`atlas.html`、`data.html`、`studio.html`、`intelli.html`、`daily.html`、`washoku.html`、`chinese-menu.html` 和 `assets/`；不发布 README、验证脚本或研究笔记。

部署后，Actions 的 `Verify public website matches this commit` 步骤会通过公网请求七个页面及所有站点资源，检查 HTTP 200、网页的 HTML 类型及文件内容是否与本次提交完全一致，等待 CDN 更新后重试，持续失败会使工作流失败。可在具备访问权限的环境手动执行 `python3 scripts/verify_public_site.py https://cafelzj.github.io/research/`。这验证公网内容发布结果，交互行为还需浏览器检查。

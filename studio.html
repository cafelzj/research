设置问答 · 本地功能说明

根据实际功能和当前数据回答。提问只查看说明；使用“填入生成示例”后发送，可生成图表。本地帮助支持下方主题，未接入开放式 AI 问答。

本地规则解析，未接入大模型。支持图表类型、字段、产品、近 N 个月、颜色和点形状；生成后可在配置区继续调整。

自然语言如何变成图表？支持哪些标准术语？

流程：原句规范化 → 识别术语与字段 → 生成结构化配置 JSON → 校验数据和图形约束 → 转换为 ECharts option → 渲染。当前使用本地规则，不会让模型编写或执行代码。

推荐模板：全部产品近12个月气泡图，X轴价格，Y轴开工率，大小按产量，点大小40px，三角形，紫色，图例在顶部。

参数 支持的表达 规则 / 默认行为
图形 散点图、气泡图、折线图、柱状图、堆叠柱状图、饼图、环形图 一条指令一个图形；未指定沿用当前类型
X / Y X轴价格、横轴price；Y轴产量、纵轴output 使用当前数据真实字段名或已登记中文名；散点/气泡需数值 X
大小 大小按产量；点大小24px；气泡最大直径48px 8–64px；前者是指标映射，后两者是像素参数
形状 圆形、方形、三角形、菱形、圆角方形 应用于散点、气泡和折线标记，不改变柱或饼的形状
颜色 红蓝、紫色、绿色、蓝色、红色；颜色#2377ad 配色方案按产品分组；十六进制主色自动生成同色系
图例 显示图例、隐藏图例；图例在顶部、图例在底部 分组固定为产品，点击图例可筛选；不能用图例代替大小字段
范围 / 产品 近1至24个月（写具体数字）；2026-09；甲醇和尿素；全部产品 月份用于饼图；未指定产品/范围时沿用当前选择
子图 / 双轴 当前尚不支持自然语言生成子图、分面或双Y轴 会明确报错，不会把两幅图的要求合并成一幅

用逗号或分号分开参数更可靠。“更大一点、好看一些”等主观描述不作为确定参数。未指定项会沿用当前配置；散点字段可按提及顺序推断，折线和柱状默认以月份为 X 轴；饼图未指定月份时取最新月。下方解析报告会展示实际配置和提示。

绘图引擎与扩展方式

        

          本工作台使用
          Apache ECharts 5.6.0，采用 Canvas 渲染。库文件随网站托管，不请求第三方
          CDN。首页历史图表使用原生 SVG。
        

        

          通过「数据 → 字段映射 → 图表配置 → ECharts
          option」生成图表。同一份数据可以切换图形、颜色、形状、大小与坐标轴；配置
          JSON 可导出、修改、再导入。新增图表可扩展
          buildOption()，无需重写数据导入逻辑。
        

        

          气泡面积与所选正数指标成比例，最大直径由滑块控制；负数大小不绘制。饼图只接受非负且合计大于零的数据。模拟数据不代表实际市场或投资建议。Apache License 2.0

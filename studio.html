绘图引擎与扩展方式

本工作台使用 Apache ECharts 5.6.0，采用 Canvas 渲染。库文件随网站托管，不请求第三方 CDN。首页历史图表使用原生 SVG。

通过「数据 → 字段映射 → 图表配置 → ECharts option」生成图表。同一份数据可以切换图形、颜色、形状、大小与坐标轴；配置 JSON 可导出、修改、再导入。新增图表可扩展 buildOption()，无需重写数据导入逻辑。

气泡面积与所选正数指标成比例，最大直径由滑块控制；负数大小不绘制。饼图只接受非负且合计大于零的数据。模拟数据不代表实际市场或投资建议。Apache License 2.0

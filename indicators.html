关系候选与公式有什么区别？

同名 / 同义候选：可能同概念，仍需核对来源、单位、频率和对象。

派生候选：名称主体一致、变换口径不同；没有公式与数值证明时不执行计算。

产业链研究假说：成本、供给、需求、库存可能相互传导，需考虑方向、时滞和混杂因素。

已验证公式依赖：须有精确输入序列、单位、时间对齐、审核版本与测试。当前目录不包含这种已验证依赖。

可复现的数据处理方法

将“数据 CP”暂按清洗、口径对齐、派生计算与质量验证设计。名字相似的两条曲线不能直接拼接或计算。

  1. 身份与溯源

    保留原始 code、来源、名称、原行业、工作表行号和文件哈希。同 code 仅行业不同可合并为多行业标签；属性冲突必须保留并审查。

  2. 确认口径，生成结构化计划

    区分地区、产品规格、品牌、渠道、频率、单位、当期/累计/期末和同比/环比。模型或规则只能提计划，不得静默选中同名指标。

  3. 拿到真实观测值再对齐

    每个观测保留 series_id、period、value、单位、频率、来源及质量信息。无观测值就不做经济异常结论；发布时点与数据期属于不同字段，回测需另存修订版本。

  4. 按公式计算，缺失不补零

    同比 = (本期 / 上年同期 − 1) × 100%；环比使用相邻的同频期。累计转当期仅用于同年度可加的月度流量，遇缺月和一二月合并发布不强推。零基期、缺期、重复期及混单位应产生质量标记。

  5. 异常分层与交叉验证

    格式与缺失 → 定义/量纲冲突 → 基期与恒等式 → 稳健离群候选 → 经济解释。统计离群只进入复核队列，不自动删数、插值或证明行业拐点。

  6. 输出与回归测试

    派生值保留操作、参与计算的日期、输入值和异常原因。用固定边界测试验证年初、缺期、重复、零基期及单位不一致，再进入图表或研究模型。

02 / CLASSIFY WITHOUT LOSING MEANING

一个指标，可以有多种研究位置

“家电”“价格”“月度”“线上”分别回答不同问题。原行业决定它在原表中放在哪里，研究角色帮助你组织供需与盈利，统计口径决定哪些数据能够比较。这些维度需要同时保留。

分类维度要回答的问题例子与注意事项当前实现
指标身份究竟是哪一条序列？命名空间、code、来源和原表定位；同名多源独立保留。保留 id、code、来源、文件哈希及原行号。
原行业原文件如何归类？一个指标可同时归入多个行业；原标签可能存在不合适的归类。原行业多标签筛选，不自动覆盖。
研究角色它解释供给、需求还是成本？价格成本、供给产能、需求消费、库存物流、贸易、财务、宏观政策。名称规则生成，可筛选；未知保留待分类。
对象与范围什么产品、地区、品牌和渠道？纯/聚合 MDI，轻/重碱，线上/线下，总量/品牌；这些差别不能作为同义词消除。名称和受控词典参与检索；全行业对象字典尚不完备。
统计口径在哪个时间和单位下量什么？日/周/月/季，原值/同比/环比，当月/累计/期末，元/台或万元。保留频率、单位、变换类别，解析常见口径和否定条件。
证据状态结论来自原表、规则还是验证？原字段、规则推断、关系候选和已验证公式的可信范围不同。显示匹配理由、候选状态与质量提示；没有已验证公式依赖。

用“空调线上零售均价”练习拆解

对象
空调；还需区分全市场和某个品牌。

04 / RELATION IS NOT YET A FORMULA

先给关系定类型，再决定能不能计算

本次导入规则生成 23,857 条派生关系候选。名称主体、来源、频率、已识别地区及口径兼容，意味着值得核对；仍要检查原始定义和真实数值。目录本身未提供公式。

关系类型能帮助你做什么成立还需要什么
同名 / 同义候选发现重复概念、别名或同名多来源。核对 code、历史、来源、单位、频率和统计范围，不能凭名字自动合并。
派生候选连接原值与同比、环比、累计等相关口径。准确公式、基期、流量/存量属性与真实观测验证。
产业链研究假说组织成本、供给、库存、需求与盈利的传导问题。核验共同驱动、方向、时滞、政策和季节性，不将上下游位置当成因果证明。
已验证公式依赖进入可执行计算计划。精确输入序列、单位换算、时间对齐、公式版本、审核与边界测试。本次目录为 0 条。

量、价、额可以互证，但要先算对单位

教学情景：某同口径家电月销量为 100 台，均价 2,000 元/台，则销售额应约为 20 万元：

100 台 × 2,000 元/台 ÷ 10,000 = 20 万元

应用到真实指标时，还要确认同品牌、品类、渠道、期间、折扣与退货处理。真实统计的“均价”不一定能按另一份销量表精确还原销售额，因此这只是需验证的会计关系候选。

同比增长率与百分点变化要分开

教学情景：份额从 20% 到 25%，是提高 5 个百分点，相对增长率则为 25%。原名称只写“同比”时，不能擅自选其中一个公式。比率、均价和期末存量也不能直接按月求和。

六条研究路径已经可以浏览

  • 原油 → 芳烃 → PU：成本传导与终端保温需求。
  • 纯碱 → 玻璃：原料库存、玻璃运行与终端需求。
  • 家电量价与渠道：零售量、均价、零售额及库存。
  • 锂电材料：区分 LFP 正极、LiPF₆ 电解液盐与 PVDF。
  • 硅材料分支：工业硅、有机硅、多晶硅与 DMC 消歧。
  • 航运供需：船队运力、SCFI、CCFI 与吞吐量。

路径按研究问题连接节点，不宣称每个箭头都是直接化学反应或已证实经济因果。打开节点后，仍需回到结果页核对指标定义。

05 / SEPARATE QUALITY FROM ECONOMIC SIGNAL

看到异常提示，先知道它在提示哪一层

  1. 目录层：字段和定义疑点

    单位缺失、名称与频率冲突、比率名称配数量单位、来源缺失等。当前规则标出 21 条名称/频率疑点和 6 条名称/单位疑点；只是待复核，不自动改成推测的正确值。

  2. 计算层：有没有算数的条件

    重复期、缺基期、零基期、合并期、单位/来源混用、非有限值与溢出。程序保留原值，给出不能计算或需复核的原因。

  3. 统计层：变化是否值得核验

    拿到真实月度观测后，程序可用过去窗口的一阶差分 MAD 标记候选；历史不足或 MAD 为零时不假造确定分数。季节性、修订和尺度变化都可能影响结果。

  4. 研究层：变化意味着什么

    回到装置、订单、库存、政策与来源公告交叉验证。数据真实、口径变化、季节波动和采集错误都可能解释候选，不能由一个离群分数直接得出拐点或因果。

“正常”也需要检查更新时间

原表健康标记属于元数据，没有最近观测日期就不能保证新鲜度。停更序列仍可能用于历史研究，所以工具保留并可筛选，不直接删除。

06 / FROM METADATA TO OBSERVATIONS

数据处理要经过哪些关口？

这里将“数据 CP”按清洗、口径对齐、派生计算和质量验证解释。指标目录负责身份和定义；数值计算需要另行取得真实观测。当前可执行 CSV 程序限于已明确身份、单位、地区、来源的月度数据。

  1. 保留原始输入记下文件哈希、来源、日期、单位与行号，原值不覆盖。
  2. 选准序列核对 code、来源、对象和统计口径。同名不能静默拼接。
  3. 按月对齐每条序列内检查重复、缺月、合并期和单位一致性。
  4. 执行指定操作原值、同比、环比，或经确认可加的累计转当期。
  5. 输出与复核保留输入值、基期行、派生值与质量原因，再进入图表和研究。
操作适用定义关键边界
同比(本期 / 上年同月 − 1) × 100%同序列同单位；零基期、缺上年同月不能计算。率的同比定义还需单独确认。
环比(本期 / 前月 − 1) × 100%找真正前月，不能把上一个非空记录当作前月。
累计转当期同年本期累计 − 上期累计仅适用于已确认可加的流量；1 月特殊处理，缺月或合并 1–2 月不强拆，存量与比率不套用。
异常候选扫描过去窗口内的月度差分 MAD 复核只生成需检查的统计候选；不补零、删原值或使用未来值。
开发与复现：CSV 契约、命令和程序入口

必填列为 series_id,date,value,unit,frequency,region,source，可选 coverage 标注合并期。示例 CSV 为人工合成，只用于理解计算。

python3 -m indicator_lab prepare --input observations.csv --output result.json --operation yoy
python3 -m indicator_lab prepare --input cumulative.csv --output period.json --operation cumulative_to_period --measure flow

输出保留输入文件哈希、原始日期和值、输入行、基期行和质量标记。混单位/地区/来源拒绝拼接；缺失保留空值，计算溢出标记原因。

07 / KNOW WHAT IS CONNECTED

页面能做什么，哪些还需要接入和验证？

能力状态适用范围
目录导入、索引与多维筛选已实现公开页人工演示；导入 JSON 或本地服务后检索完整私有目录。
自然语言与同义词检索规则已实现受控词典、明确口径、排除条件与匹配解释；未知表达会拒绝或提示。
关系与研究路径候选与线索已实现同名消歧、名称派生候选和六条研究路径；没有已验证公式或因果。
CSV 衍生计算与候选扫描本地程序已实现月度原值、同比、环比、累计转当期；网页展示方法，计算在本地 Python 程序执行。
世界银行公共指标已连接前端登记 10 项年度指标，点击获取指定国家数值；本地连接器另支持 WDI 英文/代码检索。
大模型、向量服务未连接架构允许生成受约束检索计划；现在不把规则结果称为模型理解。
商业行业数据库需授权接入Excel 的“来源”字段不是接口或授权证明，需独立适配器和服务端凭据。
跨频、单位换算、修订回测及实证因果尚未实现需定义对齐、转换、可知时点与专项验证，不从名称自动推导。

远程的“CPI”仍要看定义

世界银行登记的是年度居民消费价格通胀率，不能直接当作本地月度 CPI 指数水平。国家、频率、单位、时期都要核对；接口缺失值按缺失显示，错误不会回退成模拟数值。

  1. 先用演示理解操作

    进入研究台，试搜 DMC、甲醇周价、空调均价同比。打开指标详情，查看频率、单位、来源、同名候选和关系状态。演示是 30 条人工元数据，没有真实观测值。

    从 DMC 消歧开始 →

  2. 再导入完整目录

    将私有资料包中的 catalog.json 解压，在“导入目录 JSON”中选择。文件只读入当前浏览器内存，不上传；刷新或关闭后需重新导入。阅读同页“研究说明”不会替换当前目录。

    回到目录导入区 →

  3. 沿路径核对候选

    按研究问题选择上下游节点，用指标身份与口径检查每条结果。搜索不到时，区分“未覆盖”“约束冲突”和“尚未接入”，不要强行用近似指标替代。

    打开产业链与关联 →

  4. 有真实观测后再计算

    用本地程序导入 Excel、保留私有索引，并按 CSV 契约准备数值。运行月度处理与质量检查，再将结果用于后续图表；公开工具页不自动取得商业数据。

整套架构怎样连接？

  1. 输入Excel 目录 / 授权 API / 独立观测 CSV
  2. 身份与溯源code、来源、定义、单位、频率、行号、文件版本
  3. 分类与关系多维标签、候选关系和公式审核状态
  4. 检索计划对象、口径、排除条件、命名空间与候选选择
  5. 计算与验证真实观测对齐、指定公式、边界检查与质量输出
  6. 研究呈现结果、解释、来源和可复核的计算记录

当前前端和 Python 检索器各自实现规则解析，共同要求不放宽明确口径；不保证任意自然语言句子在两端完全一致。未来模型只生成受约束计划，仍需经过身份、口径与权限检查。

信息怎样穿过越来越深的网络

层间信息流处理深度方向的问题：历史层怎样被选择，多条表示怎样交流，怎样控制额外带宽与训练稳定性。

2026-01-01—2026-11-14 · 官方公告、论文、模型卡与实现 · 动画为教学示意

在深度方向选择与传递信息

比较标准残差、AttnRes、mHC 与 GR，观察各自的读写方式。

图示的简化与适用范围

向量投影和门值为教学参数。双随机约束不自动保证全网络无损；多残差流不是多个 Agent。

核验至 2026-11-14。以下把论文/官方实现披露与教学推导分开。公式使用单个 token 的表示以简化书写；其中涉及序列注意力的子层仍会访问其他 token。这里的“层”有时指 Attention 或 FFN 一个子层，不能直接与厂商 Decoder block 数相乘比较。

先建立三个坐标轴

设输入有 T 个 token，每个 token 的隐藏向量有 d 个通道，模型有 L 个计算子层：

  • 序列轴 t：这一层的第 t 个 token 去读哪些前文 token？Softmax Attention、MLA、稀疏注意力、KDA/GDN、CED 的 KV 设计主要处理这一轴。
  • 深度轴 l：第 l 层怎样拿到早先各层算出的表示？本篇的残差连接、AttnRes、HC/mHC、GR处理这一轴。
  • 通道/专家轴：每个 token 的特征如何变换、让哪些专家计算？FFN、MoE、LatentMoE主要处理这一轴。

因此，“Attention Residuals”里的 attention 不是又扩大了一次前文窗口；“四路残差”不是四个 Agent，也不是四份独立语言模型。它们可以与沿序列轴的注意力改进同时采用。更深的内部网络，也不等于聊天时多写了几千个思考 token。

为什么加法残差仍值得改

传统 PreNorm 子层可写成：

\[x_{l+1}=x_l+F_l(\mathrm{Norm}(x_l)).\]

展开后，当前流包含初始 embedding 与以前各子层输出的和。优点是有一条直接传递旧状态的通路，训练很深的网络比完全串联变换容易。问题并不是“以前结果完全丢失”，而是所有增量混在同一个 d 维向量里，后层不容易单独挑回某一层的结果。随着增量累积，早期信号可能被后续内容和尺度变化淹没。

教学比喻：每位分析师都在同一张草稿上直接叠写，后面的同事能看到总稿，却不一定能单独调阅第二位同事的原始分析。AttnRes保留可选的历史稿；mHC/GR则增加并行草稿槽位，再设计读写规则。这个比喻只帮助理解拓扑，不表示某个槽位预先被指定成“财务专家”。

AttnRes：选择历史层或块的表示

AttnRes：让后层选择历史深度，而非一律相加

Full AttnRes 的真正计算对象

保留早先输出 v_i（包括 embedding）。第 l 层有一个可学习的“伪查询”向量 w_l；给每份旧输出算分数，再沿历史层轴做 softmax：

\[e_{i\to l}=w_l^\top\mathrm{RMSNorm}(v_i),\quad \alpha_{i\to l}=\frac{\exp(e_{i\to l})}{\sum_{j<l}\exp(e_{j\to l})},\quad h_l=\sum_{i<l}\alpha_{i\to l}v_i.\]

三个容易写错的细节：w_l本身是每层训练得到的参数，并非普通自注意力那种由当前token线性投影产生的动态query；但分数依赖当前token的旧表示，所以权重仍随内容改变。RMSNorm用于key的打分，防止大幅值来源自动占优势；value仍是未按此步骤归一化的原输出。softmax在前层/块维度上，不是在单词位置维度上。

依据：官方仓库，Overview与PyTorch伪代码 ↗、K3报告§2.2，式8–10 ↗。仓库明确在Attention与MLP之前各做一次读取；伪码的block_size按ATTN+MLP子层计数。

一个可复算的教学例子

假设三份历史输出在某个观测方向上的投影为2、6、−1；本次学到的权重为0.7、0.2、0.1，则读取值是2.5。换一个token，其权重可以不同。这只是人为指定的投影与权重，用来展示“选择性读”，不是模型真实层含义，也不是实验结果。

softmax组合不等于“所有旧信息无损保存”：它仍把多份向量压回一份供子层计算，权重可能忽略有用来源；softmax非负也不代表所有特征贡献都是正的，因为value可以有负坐标。

为什么实际采用 Block AttnRes

Full形式需要让所有历史输出活到后面，带来深度方向的保存和流水线跨卡通信。Block形式把若干子层的输出先相加为b_n，只保留已完成块以及当前块的部分和，再在这些块级来源之间做attention。它保留跨大段深度的选择，牺牲块内部逐子层的精细寻址。

仅计这部分额外状态，Full按token为O(Ld)，N块版本为O(Nd)；整批训练还要乘batch与序列长度，不能说整个模型内存已经降为O(Nd)。块内加法与块间读取配合缓存、重计算、融合核后，才可能把理论方法变成低开销实现。论文报告约8块能保留大部分收益，是其测量结论，不是所有模型最优块数。方法与作者实验范围 ↗、官方伪码与实验表 ↗。

何时值得：层数较多、旧特征被稀释且有能力共同优化显存/流水线的训练。何时不宜直接下结论：小模型、内存带宽紧、跨卡通信敏感的部署，或只允许沿用一个已有普通残差checkpoint的场景。这是架构训练改动，不是给旧API加一个提示词即可开启。

mHC：多路残差与受约束混合

mHC：多路残差能交流，也要防止连续混合失控

从一张草稿变成n张草稿

把状态扩为X_l∈R^{n×d}；但昂贵Attention/FFN仍接收d维输入。用a_l从n条流读成一条，F计算，再用b_l把新结果写回n条流，同时P_l控制原有n条流之间怎样交换：

\[X_{l+1}=P_lX_l+b_lF_l(a_lX_l).\]

其中a为1×n，b为n×1，P为n×n。一般HC允许这些连接随输入变化，表达力增强，但多层P连乘可能放大或压扁信号。教学例：若某方向每层放大1.2倍，十层后约6.19倍，长网络更危险。

双随机约束具体是什么

mHC对残差混合矩阵施加：

\[P_{ij}\ge0,\quad P\mathbf1=\mathbf1,\quad\mathbf1^\top P=\mathbf1^\top.\]

即元素非负、每行和每列都为1。实现先把未约束分数指数化为正矩阵，再交替做行/列归一化（Sinkhorn–Knopp）；读门使用sigmoid，写门使用2×sigmoid。论文取20次迭代，得到近似约束，不是有限步自动精确满足。mHC论文§3–4，式3/6/8/9 ↗。

核对代码：DeepSeek V4官方参考实现0 ↗。张量保留[batch, seq, hc, d]，读入聚合、子层计算、混合旧状态与回写分开；Attention和FFN均经过该过程。代码注释把pre与Sinkhorn概括在一起，精确定义应以论文/核函数为准，不能误说三个门都必须双随机。

“稳定”不能解读成“每条流原封不动”

下面是独立数学教学推导。令

\[P=\begin{bmatrix}0.75&0.25\\0.25&0.75\end{bmatrix},\quad X=\begin{bmatrix}3\\1\end{bmatrix}.\]

则PX=(2.5,1.5)^T，总和仍为4，但两流差异由2缩为1；继续混合会趋近(2,2)。这个示例矩阵在精确算术下一步仍可逆，差异收缩本身不能证明信息丢失。双随机集合也包含两行均为(0.5,0.5)的不可逆平均矩阵，因此双随机约束不等于P=I，也不提供普遍的无损保证。它对纯线性混合路径具有非扩张性质（谱范数≤1），且此类矩阵连乘仍保持双随机；这不等于整个含F、输入依赖门和加法注入的网络都不存在梯度爆炸、消失或表达坍缩。

成本与证据

n路残差扩大激活、内存读写及流水线传输，昂贵子层的输入宽度不扩大，并不意味着成本为零。原论文4路训练的约6.7%额外开销建立在融合核、重计算和通信重叠等优化上；不是任意框架或后续V4.1实现的固定成本。论文§4.3与§5 ↗。

作者也报告有限Sinkhorn迭代带来偏离，实测复合增益最大约1.6；这正说明理论精确矩阵与数值工程要分开。看mHC是否有效，应检查受控消融、激活/梯度幅度、异常训练步、内存带宽和最终下游效果，不能仅因“有数学约束”就推出业务能力领先。后续模型的Single-Pass mHC属于进一步实现变化，不宜直接套用原论文完整拓扑与成本。

GR：逐通道读取与门控写回

Qwen GR：把表达力花在细粒度读门，而非矩阵混合

与mHC共同点和分叉点

Qwen3.8-Flash-Next同样用4条残差流。但GR删掉n×n的残差混合P：旧分支继续保留各自状态，改为逐通道、逐分支动态读取，再以每分支一个标量写回。门由全部分支共同决定，而不是只看最后一条。GR在Attention和MLP各有独立模块。官方仓库Residual说明 ↗、论文§2.2，式30–34 ↗。

压缩写法与教学理解

以n=4，先各分支RMSNorm成R̂_i；令g=σ(低秩网络(vec(R̂)))，其形状为4×d；s=2σ(另一投影(vec(R̂)))，其形状为4。核心可写为：

\[x=\tfrac14\sum_{i=1}^{4}g_i\odot\widehat R_i,\quad y=F(x),\quad R'_i=R_i+s_i y.\]

这里为教学省略了门网络中的缩放与矩阵形状；原式可核验低秩r=d/8。g是sigmoid门，不是分支间softmax，四条流的门不要求相加为1。 归一化已进入GR读取，生产设计不是再机械叠一个相同PreNorm。

教学例：两条分支在两个通道的归一化向量分别为(1,−1)、(−1,1)，读门分别为(.9,.2)、(.3,.9)，两个通道跨分支门值之和分别为1.2和1.1，并不要求等于1。按两路平均读得(.30,.35)，可以分别挑两条分支更有用的通道。若给新输出y=(2,0)、写门s=(.2,1.8)，则两路分别加入(.4,0)、(3.6,0)。这是人为例子，不声称分支有固定语义分工。由于读门依赖全部分支，虽然没有显式P混合，分支之间仍会通过共享F的读写间接交流。

为什么删混合可能有意义，为什么不能宣布全面胜出

Qwen作者在其消融下发现：逐通道读取比再细化写门更值得，加入P没有显著收益；删P还省一次整流读取。4路仍有额外带宽成本，作者结合FP8状态与融合读写核降低搬运量。它不是“mHC的另一个名字”，也不是“更多分支所以少用显存”。官方架构解读 ↗、论文方法与效率分析 ↗。

值得保留的反证：同一论文的受控比较中，Full AttnRes在加GatedNorm后训练loss仍更低；GR的选择包含效率、稳定性与下游等因素。不能仅凭这一篇就说GR在所有模型上比AttnRes/mHC更强。作者还报告某些稀疏分支方案预训练指标几乎不变，后训练后质量却明显变差，说明架构消融应跨训练阶段复核，而非只挑一个loss。

LatentMoE、对照与技术沿革

Stable LatentMoE不是第四种残差法

它改的是专家内部特征路径：共享专家处理全宽x；路由专家先读较窄潜在向量z=W_down x，在潜在空间变换，再上投影。K3取d=7168、潜在宽3584，896个路由专家中每token选16，并保留2个全宽共享专家。窄路径减少路由通信/专家输入宽度，但不等于压缩了所有隐藏状态或所有KV。官方K3模型规格 ↗、报告§2.3 ↗。

稳定措施分别针对两类问题：专家聚合后、上投影前加RMSNorm，加有界SiTU-GLU抑制内部离群幅值；Quantile Balancing根据全局batch路由分数分位数调专家偏置，减少专家过载/闲置。偏置影响选择而不加入混合权重，下一训练步才生效；推理时偏置冻结。因此不能说每条用户请求都被重新求解为严格均匀分配，也不能把训练路由均衡当成所有设备实时负载完美均衡。报告式11–14与§2.3.3 ↗。

教学上可把它理解为“专家工作室的材料先压成更便于传输的工作件，再送给不同专家；另设调度办法避免人人挤到同一专家”。这里专家是神经网络参数块，不是具备职业身份、互相聊天的Agent。

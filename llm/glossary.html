词元

Token

token / Token / 词元单位

怎样工作

Hidden State

hidden state / 隐状态 / 表征

怎样工作

因果遮罩

Causal Mask

causal mask / 因果mask / 下三角mask

限制当前位置不能读到尚未发生的未来位置。

怎样工作

差量更新规则

Delta Rule

Delta rule / 差量规则 / 关联纠偏

先估计已有记忆，再只写入新值与估计之间的差额。

怎样工作

研究场景
以教学状态100、新值120说明更新趋向新值，而非累加成220。
容易误读
Delta纠错不是事实核查，也不是推理时永久微调模型参数。

对比DeepSeek路由专家权重与其主KV缓存时，分别按32与16的分组口径算账。
容易误读
同叫FP4不能直接交换量化字节；仅看模型卡FP4标签不足以确定推理内核。
